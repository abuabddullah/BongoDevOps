## ১. রিক্যাপ ও আজকের রোডম্যাপ

কোর্সে এ পর্যন্ত শেষ হওয়া মাইলস্টোন: গিট ও গিটহাব, লিনাক্স ও শেল স্ক্রিপ্টিং, কম্পিউটার নেটওয়ার্কিং। এখন চলছে পাইথন, আর ক্লাস ০১ থেমেছিল `input()` পর্যন্ত এসে।

ক্লাসের শুরুতে ডাটা টাইপ নিয়ে একটা ছোট কুইজ হয়েছে:

| স্ক্রিনের মান | টাইপ | ডেভঅপস উদাহরণ |
|---|---|---|
| `"us-east-1"` | `str` | রিজিয়ন, আইপি অ্যাড্রেস, গিট ব্রাঞ্চের নাম |
| `22` | `int` | পোর্ট নম্বর |
| `78.4` | `float` | সিপিইউ ব্যবহারের শতাংশ |
| `["10.0.0.1", "10.0.0.2"]` | `list` — ভেতরে **যেকোনো** ডাটা টাইপ থাকতে পারে | সার্ভারের আইপি |
| `{"image": "nginx"}` | `dict` — `key: value` জোড়া, ভেতরে যেকোনো টাইপ, এমনকি আরেকটা ডিকশনারি বা লিস্টও থাকতে পারে | কন্টেইনারের কনফিগ |

ক্লাস ০১ ছিল ডাটা **ধরে রাখা** নিয়ে। ক্লাস ০২ সেই ডাটা দিয়ে **কাজ করা** নিয়ে:

```
ডাটা টাইপ (ক্লাস ০১)
      ↓
সংগ্রহের ওপর কাজ            → লিস্ট ও ডিকশনারি অপারেশন
      ↓
একই কাজ বারবার               → লুপ
      ↓
হিসাব ও তুলনা                → অ্যারিথমেটিক ও কম্পারিজন অপারেটর
      ↓
সিদ্ধান্ত                    → if / elif / else, and / or
      ↓
গুছিয়ে রাখা ও পুনর্ব্যবহার    → ফাংশন
      ↓
বাস্তব জিনিসের মডেল          → ক্লাস ও অবজেক্ট
```

কোর্সের রিপোজিটরিতে সাতটা ল্যাব এক্সারসাইজ আছে। শিক্ষকের পরামর্শ: আগে কনসেপ্ট বুঝুন, তারপর আস্তে আস্তে ল্যাবগুলো করুন। এখনো কোনো ডেডলাইন দেওয়া হয়নি।

## ২. লিস্ট: অ্যাক্সেস ও ট্রাভার্স

```python
grocery_list = ["Eggs", "Milk", "Bread"]
```

- স্কয়ার ব্র্যাকেটের ভেতরের জিনিসগুলোকে বলে **আইটেম (Item)** বা **এলিমেন্ট (Element)**।
- অবস্থানকে বলে **ইনডেক্স (Index)**, আর গোনা শুরু হয় **০** থেকে (জিরো-বেসড)।
- `grocery_list` নিজে একটা **ভেরিয়েবল**, যার ভেতরে একটা লিস্ট রাখা আছে।

### ২.১ ইনডেক্স দিয়ে অ্যাক্সেস

```python
print(grocery_list[0])    # Eggs
print(grocery_list[1])    # Milk
print(grocery_list[-1])   # Bread  ← শেষ আইটেম, লিস্ট যত বড়ই হোক
```

ইঞ্জিনিয়ারের নিয়মে চালান:

```bash
python3 list.py
```

**টার্মিনাল টিপস:** `python3 li` লিখে **Tab** চাপুন। শেল নিজেই ফাইলের নাম পূরণ করে দেবে। যেকোনো কমান্ড-লাইন টুলে এটা কাজ করে।

### ২.২ `-1` কেন দরকারি

তিনটা আইটেম হলে শেষেরটা চোখেই দেখা যায়। আসল প্রোগ্রামে তা সম্ভব না। ধরুন চলতি ব্যাচের সব স্টুডেন্টের একটা লিস্ট আছে। **সবার শেষে** কে জয়েন করেছে জানতে আপনি গুনতে বসবেন না। ইনডেক্স `-1` চাইলেই সেই স্টুডেন্টের রেকর্ড চলে আসবে, অনেকটা `{"name": "Rahim", "age": 21}`-এর মতো।

### ২.৩ ট্রাভার্স / ইটারেট করা

অবস্থান যখন **জানা নেই**, যেমন ডাটাবেস থেকে এক লাখ আইটেম এসেছে, তখন প্রোগ্রামকে একটা একটা করে দেখতে হয়: প্রথমটায় যাও, তারপর পরেরটায়, তারপর তার পরেরটায়। প্রতিটি আইটেমে একবার করে যাওয়াকে বলে লিস্ট **ট্রাভার্স (Traverse)** করা বা **ইটারেট (Iterate)** করা। কীভাবে করতে হয় তা অধ্যায় ৬-এ আছে।

> **সূক্ষ্ম সংশোধন:** ক্লাসে অবস্থান দিয়ে একটা আইটেম পড়াকে "ইনডেক্সিং বা স্লাইসিং" বলা হয়েছে। এ দুটো আলাদা জিনিস। **ইনডেক্সিং (Indexing)** দেয় **একটা** আইটেম: `grocery_list[1]` → `"Milk"`। **স্লাইসিং (Slicing)** দেয় একটা **ছোট লিস্ট**, `start:stop` রেঞ্জ ব্যবহার করে: `grocery_list[1:3]` → `["Milk", "Bread"]` (stop অবস্থানটা নিজে অন্তর্ভুক্ত হয় না)।

### ২.৪ কমেন্ট আউট করা

লাইনগুলো সিলেক্ট করে `Ctrl + /` চাপুন। পাইথন লাইন ধরে ধরে যায়, `#` দেখলে সেই লাইন বাদ দেয়। একটা `print()` বাদে বাকি সব কমেন্ট করা থাকলে শুধু ওই একটা কাজই হবে।

## ৩. লিস্ট অপারেশন

কাল একজন নতুন স্টুডেন্ট ভর্তি হবে। কেউ চলে যাবে। কেউ লিস্টে আছে কি না দেখতে হবে। লিস্ট **পরিবর্তনযোগ্য (Mutable)**, আর এই কাজগুলোর জন্য নিচের টুলগুলো আছে।

### ৩.১ যোগ করা: `append()` ও `insert()`

```python
grocery_list = ["Eggs", "Milk", "Bread"]

grocery_list.append("Apples")       # সবসময় শেষে বসে
print(grocery_list)                 # ['Eggs', 'Milk', 'Bread', 'Apples']

grocery_list.insert(1, "Butter")    # আপনি যে অবস্থান বলবেন সেখানে বসে
print(grocery_list)                 # ['Eggs', 'Butter', 'Milk', 'Bread', 'Apples']
```

| | `append(x)` | `insert(i, x)` |
|---|---|---|
| আইটেম কোথায় বসে? | সবসময় **শেষে** | ইনডেক্স `i`-তে; পরের সবাই এক ঘর ডানে সরে যায় |
| কী কী দিতে হয় | শুধু আইটেম | আগে অবস্থান, তারপর আইটেম |

### ৩.২ সরানো: `remove()` ও `pop()`

```python
grocery_list.remove("Milk")         # মান (Value) ধরে সরায়
print(grocery_list)                 # ['Eggs', 'Butter', 'Bread', 'Apples']

removed = grocery_list.pop(2)       # অবস্থান ধরে সরায় এবং আইটেমটা ফেরত দেয়
print(removed)                      # Bread
print(grocery_list)                 # ['Eggs', 'Butter', 'Apples']
```

**জারের ছবি:** একটা জার কল্পনা করুন। জিনিস ভেতরে ঢোকে, আর "পপ" মানে একটা বের করে আনা। কোনো সংখ্যা ছাড়া `pop()` দিলে **শেষের** আইটেমটা বের হয়, আর **স্ট্যাক (Stack)** ঠিক এভাবেই কাজ করে।

> **সূক্ষ্ম সংশোধন:** ক্লাসে কাজ দুটোকে বলা হয়েছে "পপ ইন" ও "পপ আউট"। প্রচলিত নাম হলো **পুশ (Push)** (ভেতরে রাখা) এবং **পপ (Pop)** (বের করা)। পাইথনে `append()`-ই হলো পুশ।

### ৩.৩ খোঁজা: `in` অপারেটর

ক্লাসে ৫৭ জন আছে, শিক্ষক ডাক দিলেন "ইফতেখার ভাই আছেন?" এটাই সার্চ, বা "সার্চ দ্য খোঁজ"। আরেকটা ছবি: বাসা থেকে বাজারের লিস্ট ধরিয়ে দেওয়া হয়েছে; দোকানে গিয়ে আপনি লিস্টটা বের করে দেখছেন "ডিম কি ছিল?", থাকলে তবেই কিনছেন।

```python
if "Eggs" in grocery_list:
    print("Yes, you need to buy eggs.")
```

`"Eggs" in grocery_list` একটা **শর্ত বা কন্ডিশন (Condition)**। এর ফল হয় `True` নয়তো `False`।

`in` যেকোনো **সিকোয়েন্স (Sequence, অর্থাৎ ক্রমানুসারে সাজানো ডাটা)**-এ কাজ করে। স্ট্রিংয়ের ক্ষেত্রে এটা **সাবস্ট্রিং (Substring)** খোঁজে, মানে বড় লেখার ভেতরের ছোট একটা অংশ:

```python
print("Ifte" in "Iftekhar")     # True
print("ifte" in "Iftekhar")     # False  ← কেস-সেনসিটিভ!
```

**বাস্তব ব্যবহার:** একজন স্টুডেন্ট বলছেন "আমি কোর্সের ভিডিও দেখতে পারছি না।" প্রথম কাজ: তাঁর ইমেইলটা কি ভর্তি হওয়া স্টুডেন্টদের লিস্টের `in`-এ আছে?

### ৩.৪ গোনা: `len()`

```python
print(len(grocery_list))    # 3
```

তিনটা আইটেম চোখেই গোনা যায়। লাখ লাখ হলে "গুনতে গুনতে চুল পেকে যাবে"। `len` হলো *length*-এর সংক্ষিপ্ত রূপ, যেভাবে `str` হলো string আর `int` হলো integer-এর।

**সংখ্যা আর ইনডেক্স গুলিয়ে ফেলবেন না।** এটা যাচাই করতেই শিক্ষক ইচ্ছা করে জিজ্ঞেস করেছিলেন "কয়টা এলিমেন্ট আছে?":

| লিস্ট | মোট সংখ্যা (`len`) | ইনডেক্স |
|---|---|---|
| `["Eggs", "Milk", "Bread"]` | **৩** | 0, 1, 2 |

শেষ ইনডেক্স সবসময় `len(list) - 1`।

### ৩.৫ সাজানো: `sort()`

মানুষ স্বভাবতই জিনিস সাজায় A, B, C কিংবা 1, 2, 3 ক্রমে। এটাই **সর্টিং (Sorting)**।

```python
items = ["Milk", "Bread", "Cocoa", "Apples", "Eggs"]
items.sort()
print(items)        # ['Apples', 'Bread', 'Cocoa', 'Eggs', 'Milk']

numbers = [4, 3, 7, 1]
numbers.sort()
print(numbers)      # [1, 3, 4, 7]
```

| ক্রম | অর্থ | কীভাবে |
|---|---|---|
| **অ্যাসেন্ডিং (Ascending)**, ঊর্ধ্বক্রম (ডিফল্ট) | A → Z, ছোট → বড় | `numbers.sort()` |
| **ডিসেন্ডিং (Descending)**, অধঃক্রম | Z → A, বড় → ছোট | `numbers.sort(reverse=True)` |

### ৩.৬ দুটো লিস্ট জোড়া লাগানো: `+` (কনক্যাটিনেশন)

দুই ব্যাচকে একসাথে রিইউনিয়নে ডাকা হচ্ছে। প্রতিটা ব্যাচ একটা লিস্ট। সবাইকে ইমেইল ও ফোন করার জন্য দরকার একটাই মিলিত লিস্ট।

```python
list1 = [4, 3, 7, 1]
list2 = [10, 6, 2]

full_list = list1 + list2
full_list.sort()
print(full_list)    # [1, 2, 3, 4, 6, 7, 10]
```

যে `+` দিয়ে স্ট্রিং জোড়া লাগে (ক্লাস ০১), সেই `+` দিয়েই লিস্ট জোড়া লাগে। **দুই পাশেই লিস্ট থাকলে তবেই এটা কাজ করে।**

### ৩.৭ ⚠️ `None`-এর ফাঁদ

`append()`, `insert()`, `remove()` আর `sort()` লিস্টটাকে **নিজের জায়গাতেই (In place)** বদলে দেয় এবং **কিছুই ফেরত দেয় না** (`None`)। ক্লাসে লাইভ কোডিংয়ে এই ভুলটাই হয়েছিল:

```python
print(full_list.sort())             # None   ← লিস্ট সর্ট হয়েছে, কিন্তু sort() কিছু ফেরত দেয় না

all_ips = prod_ips.append(dev_ip)   # all_ips-এর মান None!
```

সঠিক নিয়ম: এক লাইনে কাজটা করুন, পরের লাইনে লিস্টটা ব্যবহার করুন।

```python
full_list.sort()
print(full_list)
```

মূল লিস্ট না বদলে একটা **নতুন** সাজানো লিস্ট চাইলে বিল্ট-ইন `sorted()` ব্যবহার করুন:

```python
print(sorted([3, 1, 2]))    # [1, 2, 3]
print(sorted([3, 1, 2], reverse=True))     # [3,2,1]
```

### ৩.৮ ডেভঅপস উদাহরণ: আইপি সংগ্রহ

```python
prod_ips = ["10.0.1.10", "10.0.1.11"]
dev_ip = "10.0.2.20"                    # একটামাত্র স্ট্রিং

prod_ips.append(dev_ip)                 # একটা আইটেম → append
print(prod_ips)                         # ['10.0.1.10', '10.0.1.11', '10.0.2.20']
```

`prod_ips` আগে থেকেই একটা লিস্ট, তাই নতুন লিস্ট বানানোর দরকার নেই। ওটাতেই `append` করে দিন।

ডেভ আইপিগুলোও যদি একটা **লিস্ট** হয়, তখন `+`:

```python
prod_ips = ["10.0.1.10", "10.0.1.11"]
dev_ips = ["10.0.2.20", "10.0.2.21"]

all_ips = prod_ips + dev_ips
print(all_ips)      # ['10.0.1.10', '10.0.1.11', '10.0.2.20', '10.0.2.21']
```

আর গুলিয়ে ফেললে:

```python
prod_ips + dev_ip
# ❌ TypeError: can only concatenate list (not "str") to list
```

### ৩.৯ সারসংক্ষেপ

| আপনি চান… | ব্যবহার করুন | মূল লিস্ট বদলায়? | কী ফেরত দেয় |
|---|---|---|---|
| শেষে একটা আইটেম যোগ | `lst.append(x)` | হ্যাঁ | `None` |
| নির্দিষ্ট অবস্থানে যোগ | `lst.insert(i, x)` | হ্যাঁ | `None` |
| মান ধরে সরানো | `lst.remove(x)` | হ্যাঁ | `None` |
| অবস্থান ধরে সরানো | `lst.pop(i)` | হ্যাঁ | সরানো আইটেমটা |
| আছে কি না দেখা | `x in lst` | না | `True` / `False` |
| আইটেম গোনা | `len(lst)` | না | একটা সংখ্যা |
| সাজানো | `lst.sort()` | হ্যাঁ | `None` |
| সাজানো কপি | `sorted(lst)` | না | নতুন লিস্ট |
| দুটো লিস্ট জোড়া | `lst1 + lst2` | না | নতুন লিস্ট |

> **সূক্ষ্ম সংশোধন:** ক্লাসে `append`, `insert`, `in`, `len`, `sort` সবগুলোকেই আলগাভাবে "কিওয়ার্ড" বলা হয়েছে। ইন্টারভিউতে সঠিক নামটা গুরুত্বপূর্ণ:
> - **কিওয়ার্ড (Keyword):** ভাষার নিজের জন্য সংরক্ষিত শব্দ: `in`, `for`, `if`, `def`, `class`, `and`, `or`।
> - **বিল্ট-ইন ফাংশন (Built-in Function):** একা একাই ডাকা হয়: `len(x)`, `print(x)`, `sorted(x)`।
> - **মেথড (Method):** কোনো অবজেক্টের নিজের ফাংশন, ডট দিয়ে ডাকা হয়: `grocery_list.append(x)`, `grocery_list.sort()`, `name.upper()`।

## ৪. অ্যালগরিদমিক চিন্তা: কেন শিখছি

সিনট্যাক্স জানা জরুরি। কিন্তু শিক্ষকের বক্তব্য ছিল, সিনট্যাক্স সহজ অংশ ("পানি ভাত")। আসল জিনিস হলো **অ্যালগরিদম (Algorithm)**:

> **অ্যালগরিদম হলো সেই ধাপগুলো, যেগুলো অনুসরণ করে আমরা একটা কাজ সম্পন্ন করি।**

রিইউনিয়নের উদাহরণটা অ্যালগরিদম আকারে:

1. আমার কাছে `list1` আছে।
2. আমার কাছে `list2` আছে।
3. `+` দিয়ে দুটোকে জোড়া লাগাও।
4. ফলাফলটা সর্ট করো।
5. প্রিন্ট করো।

এই ধাপে ধাপে পরিকল্পনাই সিনট্যাক্সকে ফলাফলে পরিণত করে।

### পাঠের পেছনের পাঠ

শিক্ষক একবার টানা ১২ ঘণ্টা পাইথন পড়েও বুঝতে পারেননি লিস্ট আসলে কী কাজে লাগে। "এই লিস্ট দিয়ে আমি বাস্তব জীবনে কী করব?" সারারাত রামায়ণ পড়ে "সীতা কার বাপ" জিজ্ঞেস করার মতো অবস্থা। রিইউনিয়নের উদাহরণেই উত্তরটা আছে: দুই ব্যাচকে এক লিস্টে আনা, সাজানো, তারপর সবাইকে ফোন করা।

> **আসল শেখা হলো আপনি কীভাবে চিন্তা করছেন।** প্রতিটা টপিক শেষে একটু থেমে নিজেকে জিজ্ঞেস করুন: *"এটা আমি কেন শিখছি? এর বাস্তব উদাহরণ কী হতে পারে?"* **কেন**-টা না ভেবে শুধু টিউটোরিয়াল দেখে টাইপ করে গেলে শেখাটা কখনোই মসৃণ হয় না।

## ৫. ডিকশনারি: অ্যাক্সেস, যোগ, আপডেট

```python
employee_directory = {
    "EMP101": "Anis Rahman",
    "EMP102": "Sultana Kamal",
    "EMP103": "Tamim Iqbal"
}
```

**ডিকশনারি চেনার উপায়:** কার্লি ব্রেস `{ }` (সেকেন্ড ব্র্যাকেট), ভেতরে `key: value` জোড়া। এর বদলে স্কয়ার ব্র্যাকেট `[ ]` দেখলে সেটা লিস্ট। দেখেই স্ট্রাকচার চিনতে পারাটা প্রথম দক্ষতা।

### ৫.১ কী দিয়ে অ্যাক্সেস

লিস্ট আইটেম দেয় **অবস্থান** ধরে (`0`, `1`, `2`)। ডিকশনারিতে কোনো অবস্থান নেই। আপনি **কী (Key)** দেবেন, সে তার **সংশ্লিষ্ট মান (Corresponding Value)** ফেরত দেবে, যেভাবে অভিধানে "father" খুঁজলে "বাবা" পাওয়া যায়।

```python
print(employee_directory["EMP102"])     # Sultana Kamal
print(employee_directory["EMP103"])     # Tamim Iqbal
```

### ৫.২ নতুন আইটেম যোগ

ব্যাচে ১৬০ জন স্টুডেন্ট। কাল আরো পাঁচজন ভর্তি হবে। একজনকে যোগ করতে:

```python
employee_directory["EMP104"] = "Sakib Al Hasan"
```

ডিকশনারির নাম, স্কয়ার ব্র্যাকেটে নতুন কী, `=`, তারপর মান। এটুকুই।

### ৫.৩ পুরনো আইটেম আপডেট: ডাটা ম্যানিপুলেশন

`EMP101`-এর নাম ভুল এন্ট্রি হয়েছিল। হওয়ার কথা খলিলুর হাসান।

```python
employee_directory["EMP101"] = "Khalilur Hasan"
print(employee_directory)
# {'EMP101': 'Khalilur Hasan', 'EMP102': 'Sultana Kamal',
#  'EMP103': 'Tamim Iqbal', 'EMP104': 'Sakib Al Hasan'}
```

ডিকশনারির সব খেলা **কী দিয়ে**। আছে এমন কী দিলে তার মান **ওভাররাইট (Overwrite)** হয়। নেই এমন কী দিলে নতুন আইটেম **যোগ** হয়। জমা থাকা ডাটা এভাবে বদলানোকেই বলে **ডাটা ম্যানিপুলেশন (Data Manipulation)**।

**ডেভঅপস ব্যবহার:** ডাইনামিক আইপি বসানো: "এখন থেকে এই আইপিটা ব্যবহার করো", অর্থাৎ একই কী-এর পুরনো মান ওভাররাইট করে দেওয়া।

### ৫.৪ নাম অনেক, আকার একটাই

| কোথায় | কী নামে ডাকে |
|---|---|
| পাইথন | **ডিকশনারি** (`dict`) |
| জাভাস্ক্রিপ্ট | অবজেক্ট (Object) |
| কম্পিউটার সায়েন্সে সাধারণভাবে | হ্যাশ ম্যাপ (Hash Map) |
| ফাইল ও এপিআই | জেসন বা JSON (JavaScript Object Notation) |

কার্লি ব্রেসের ভেতরে কী-ভ্যালু জোড়া, এটা একটা বৈশ্বিক রীতি। শিক্ষকের দাবি: ইঞ্জিনিয়ারিং জীবনে **সবচেয়ে বেশি** কাজ করতে হবে এই আকারের ডাটা নিয়ে, আর ডাটা JSON আকারে পেলে ইঞ্জিনিয়ারের হাসি সবচেয়ে চওড়া হয়। JSON নিয়ে আলাদা আলোচনা হবে পরের ক্লাসে।

> **সূক্ষ্ম সংশোধন:** পাইথনের ডিকশনারি আর JSON *দেখতে* এক রকম, কিন্তু একই জিনিস নয়। **JSON একটা টেক্সট ফরম্যাট**, যা ফাইল ও এপিআই রেসপন্সে ব্যবহার হয়। **ডিকশনারি হলো পাইথনের মেমোরিতে থাকা জীবন্ত ডাটা স্ট্রাকচার**। পাইথন এক রূপ থেকে আরেক রূপে নিয়ে যেতে পারে (`json.loads()` / `json.dumps()`), আর সেটাই পরের ক্লাসের বিষয়। আরেকটা কথা: পাইথনে "অবজেক্ট" শব্দটা "ডিকশনারি"-র চেয়ে অনেক ব্যাপক। পাইথনে **সবকিছুই** অবজেক্ট (অধ্যায় ১৪.৮ দেখুন)।

> **সূক্ষ্ম সংশোধন:** ক্লাসে বলা হয়েছে, পাইথনের বিরক্তিকর দিক হলো সব কিছুতে `print()` লাগে, অথচ ব্রাউজারের জাভাস্ক্রিপ্ট কনসোলে `2 + 2` লিখলেই উত্তর আসে। একই সুবিধা পাইথনেও আছে: ইন্টারঅ্যাক্টিভ শেলে (`python3` → `>>>`) `print()` ছাড়াই ফল দেখা যায়। `print()` লাগে **স্ক্রিপ্ট ফাইলে**, আর জাভাস্ক্রিপ্ট ফাইলের ক্ষেত্রেও কথাটা সত্য।

## ৬. লুপ

লিস্টে কিছু খোঁজার জন্য আছে `in`। কিন্তু যদি **প্রতিটা আইটেমে গিয়ে প্রতিটাকে নিয়ে কিছু করতে** চান? ট্রাভার্স বা ইটারেট করার সহজ তরিকা হলো **লুপ (Loop)**। পাইথনে লুপ দুটো: **`for`** আর **`while`**।

### ৬.১ `for` লুপ

```python
fruits = ["apple", "banana", "orange"]

for item in fruits:
    print(item)
```

আউটপুট:
```
apple
banana
orange
```

মুখে পড়ুন এভাবে: **"fruits-এর ভেতরের প্রতিটা item-এর জন্য, কিছু একটা করো।"**

গঠন:

```
for   item   in   fruits  :
───   ────   ──   ──────  ─
 │     │     │      │     └── কোলন: "এখান থেকে একটা কোড ব্লক শুরু"
 │     │     │      └──────── যে লিস্টের ভেতর দিয়ে হাঁটব
 │     │     └─────────────── কিওয়ার্ড
 │     └───────────────────── লুপ ভেরিয়েবল: এই মুহূর্তের আইটেমটা ধরে রাখে
 └─────────────────────────── কিওয়ার্ড
    print(item)      ← ইনডেন্ট করা ব্লক: প্রতি আইটেমে একবার চলে
```

চলার সময় যা ঘটে:

| রাউন্ড (ইটারেশন) | `item`-এ কী আছে | কাজ |
|---|---|---|
| ১ | `"apple"` | `apple` প্রিন্ট |
| ২ | `"banana"` | `banana` প্রিন্ট |
| ৩ | `"orange"` | `orange` প্রিন্ট |
| — | আর আইটেম নেই | লুপ বলে "আমার কাজ শেষ", বের হয়ে যায় |

প্রতিটা রাউন্ডকে বলে একটা **ইটারেশন (Iteration)**। লুপের ভেতরে আইটেমটা নিয়ে কী করবেন তা পুরোপুরি আপনার ব্যাপার: প্রিন্ট, যোগ, গুণ, অন্য কোথাও জমা রাখা।

### ৬.২ লুপ ভেরিয়েবল শুধুই একটা প্লেসহোল্ডার

```python
for x in fruits:
    print(x)        # হুবহু একই ফল
```

`item`, `element`, `x`, `y`: পাইথনের কিছু যায় আসে না। নামটার কোনো বিশেষ অর্থ নেই। এটা একটা **প্লেসহোল্ডার (Placeholder)**, যেখানে পালা করে প্রতিটা আইটেম এসে বসে।

**পাঠযোগ্য কোডের রীতি:** লিস্টের নাম **বহুবচনে (Plural)**, লুপ ভেরিয়েবলের নাম **একবচনে (Singular)**।

```python
for student in students:
for price in dollar_prices:
for ip in server_ips:
```

### ৬.৩ ইনডেন্টেশন ও কোড ব্লক

কোলনের পরে এন্টার চাপুন। এডিটর কার্সরকে **চারটা স্পেস** ভেতরে সরিয়ে দেবে। এই ফাঁকটাই **ইনডেন্টেশন (Indentation)**, আর ইনডেন্ট করা লাইনগুলো মিলে হয় একটা **কোড ব্লক (Block of Code)**।

- স্ট্যান্ডার্ড হলো **৪টা স্পেস**। ভিএস কোডে **Tab** চাপলেই বসে যায়।
- ২টা স্পেসেও চলে, যদি ব্লকের ভেতরে একই রকম রাখেন। তবে স্ট্যান্ডার্ড ৪ (PEP 8)।
- **শূন্য ইনডেন্টেশন চলবে না।** লুপের ভেতরের কাজ `for`-এর সমান্তরালে লিখলে এরর:

```python
for item in fruits:
print(item)
# ❌ IndentationError: expected an indented block after 'for' statement
```

আজ ঠিক চার জায়গায় ব্লক দেখবেন: **লুপ**, **কন্ডিশন** (`if / elif / else`), **ফাংশন** (`def`) আর **ক্লাস** (`class`)। ধরনটা সবখানে এক: লাইনের শেষে **কোলন**, তারপর **ইনডেন্ট করা ব্লক**।

কোনটা লুপের *ভেতরে* আর কোনটা *পরে*, সেটাও ইনডেন্টেশনই ঠিক করে:

```python
for item in fruits:
    print(item)      # ভেতরে: ৩ বার চলে
print("Done")        # বাইরে: লুপ শেষ হলে একবার চলে
```

### ৬.৪ হাতে-কলমে: ডলার থেকে সেন্ট

দামগুলো ডলারে লেখা: জুতা, বেল্ট, ক্যাপ। `1.50` ডলার মানে ১ ডলার ৫০ সেন্ট, অর্থাৎ ১৫০ সেন্ট। প্রতিটা দামকে সেন্টে রূপান্তর করতে হবে।

**অ্যালগরিদম:** একটা খালি লিস্ট বানাও → দামগুলোর ওপর লুপ চালাও → প্রতিটাকে ১০০ দিয়ে গুণ করো → ফলাফল `append` করো → প্রিন্ট করো।

```python
dollar_prices = [1.50, 4.99, 10.00, 25.50]
cent_prices = []                        # একটা খালি (Empty) লিস্ট, পরে ভরা হবে

for price in dollar_prices:
    cents = price * 100
    cent_prices.append(cents)

print(cent_prices)      # [150.0, 499.0, 1000.0, 2550.0]
```

`[]` লিস্ট বানানোর আরেকটা উপায়: খালি দিয়ে শুরু, পরে `append`, `insert` বা কনক্যাটিনেট করে ভরা।

ক্লাসে যেভাবে আঁকা হয়েছিল, ছোট একটা সংস্করণের ধাপে ধাপে হিসাব:

| ইটারেশন | `price` | `price * 100` | `append`-এর পর `cent_prices` |
|---|---|---|---|
| ১ | `1.5` | `150.0` | `[150.0]` |
| ২ | `2.5` | `250.0` | `[150.0, 250.0]` |
| ৩ | `3.5` | `350.0` | `[150.0, 250.0, 350.0]` |

তিনটা আইটেম, তিন রাউন্ড, তারপর লুপ থেকে বের হয়ে শেষের `print` চলে।

> **সূক্ষ্ম সংশোধন:** ফলাফলগুলো float (`150` নয়, `150.0`), কারণ float × int করলে float হয়। float-এ কখনো কখনো অতি সূক্ষ্ম ভুলও থাকে (`1.1 * 100` দেয় `110.00000000000001`)। পূর্ণ সেন্ট চাইলে লিখুন `round(price * 100)`, তখন পাবেন `[150, 499, 1000, 2550]`।

### ৬.৫ ডেভঅপসে লুপ কেন জরুরি: লগ ফাইল পড়া

লিনাক্স ক্লাসের লগ ফাইল মনে আছে? লাইনের পর লাইন, প্রতিটায় `INFO`, `WARNING`, `ERROR` বা `CRITICAL` লেখা। পাইথনে লগ স্ক্যানারের অ্যালগরিদম:

1. ফাইলটা খোলো (পড়ো)।
2. সব লাইন পড়ো। এতে লাইনগুলোর একটা **লিস্ট** পাওয়া যায়।
3. লাইনগুলোর ওপর লুপ চালাও।
4. `if "ERROR" in line` → লাইনটা প্রিন্ট করো, অথবা আরেকটা লিস্টে `append` করো।

একই অ্যালগরিদম লাইনের একটা লিস্টের ওপর (আসল ফাইল পড়া পরের ক্লাসে):

```python
log_lines = [
    "INFO server started",
    "ERROR disk full",
    "WARNING cpu high",
    "ERROR db connection lost",
]

error_lines = []
for line in log_lines:
    if "ERROR" in line:
        error_lines.append(line)

print(error_lines)      # ['ERROR disk full', 'ERROR db connection lost']
```

`grep ERROR app.log` পর্দার আড়ালে আপনার হয়ে এই কাজটাই করে। `grep` আর `sed` দিয়ে যা যা করেছেন, সবই পাইথন স্ক্রিপ্ট হিসেবে লেখা যায়। খেয়াল করুন, এই ছোট্ট প্রোগ্রামে একসাথে আছে **লিস্ট**, **লুপ**, **`in`** দিয়ে সাবস্ট্রিং খোঁজা, **কন্ডিশন** আর **`append`**।

### ৬.৬ অন্য জিনিসের ওপর লুপ

লুপ শুধু লিস্ট নয়, যেকোনো সিকোয়েন্সে চলে:

```python
for ch in "dev":
    print(ch)           # d, e, v আলাদা আলাদা লাইনে
```

### ৬.৭ `while` লুপ (ক্লাসে নাম বলা হয়েছে, দেখানো হয়নি)

`for` আর `while`-এর ব্যবহার আলাদা। `for` একটা সংগ্রহের ভেতর দিয়ে হাঁটে। `while` ততক্ষণ চলতে থাকে **যতক্ষণ একটা শর্ত সত্য থাকে**:

```python
count = 1
while count <= 3:
    print("Health check", count)
    count += 1          # এর মানে: count = count + 1
```

আউটপুট:
```
Health check 1
Health check 2
Health check 3
```

শর্তটা কখনো মিথ্যা না হলে লুপ আর থামে না (**ইনফিনিট লুপ, Infinite Loop**)। থামাতে টার্মিনালে `Ctrl + C` চাপুন।

## ৭. লিস্ট কম্প্রিহেনশন

*(অ্যাডভান্সড। যাঁরা নতুন, আগে সাধারণ `for` লুপে হাত পাকান। শিক্ষকের পরামর্শও এটাই ছিল।)*

ডলার-থেকে-সেন্ট লুপে লেগেছিল চার লাইন। **লিস্ট কম্প্রিহেনশন (List Comprehension)** একই কাজ করে এক লাইনে:

```python
cent_prices = [price * 100 for price in dollar_prices]
```

লুপের সাথে মিলিয়ে দেখুন:

```
[  price * 100      for price in dollar_prices  ]
   ───────────      ──────────────────────────
   নতুন লিস্টে       সেই একই for লুপের শিরোনাম
   কী বসবে
└─ স্কয়ার ব্র্যাকেট এখানে খালি লিস্ট + append-এর ভূমিকায় ─┘
```

### ৭.১ ফিল্টারসহ: `if` বসে শেষে

"শুধু ২ ডলারের বেশি দামগুলো রূপান্তর করো":

```python
[round(price * 100) for price in dollar_prices if price > 2]
# [499, 1000, 2550]         ← 1.50 বাদ পড়েছে
```

সমতুল্য লুপ:

```python
for price in dollar_prices:
    if price > 2:
        cent_prices.append(round(price * 100))
```

### ৭.২ `if ... else` সহ: বসে `for`-এর আগে

একজন স্টুডেন্ট জিজ্ঞেস করেছিলেন: "`else` ব্যবহার করতে চাইলে?" যেমন, দাম ২-এর বেশি হলে ১০০ দিয়ে গুণ, **অন্যথায়** ১০ দিয়ে গুণ। `else`-টা শেষে লিখলে `SyntaxError` হয়, আর ক্লাসে লাইভ কোডিংয়ে সেটাই হয়েছিল। `else` থাকলে পুরো শর্তটা চলে আসে `for`-এর **সামনে**:

```python
[round(price * 100) if price > 2 else round(price * 10) for price in dollar_prices]
# [15, 499, 1000, 2550]
```

| রূপ | প্যাটার্ন | ফল |
|---|---|---|
| ফিল্টার | `[value for x in items if condition]` | শর্ত না মানা আইটেম **বাদ পড়ে** |
| বাছাই | `[a if condition else b for x in items]` | **সব আইটেম থাকে**, দুটো মানের একটা বেছে নেওয়া হয় |

### ৭.৩ কখন ব্যবহার *করবেন না*

একজন স্টুডেন্ট জানতে চেয়েছিলেন, লুপের ভেতরে অনেক লাইনের কাজ থাকলে কী হবে। উত্তর: কম্প্রিহেনশন ছোট, ৩–৫ লাইনের লুপকে সংক্ষেপ করার জন্য। ভেতরে পাঁচ-সাতটা কাজ থাকলে সাধারণ `for` লুপই লিখুন। চালাকির চেয়ে পড়তে সহজ হওয়া বেশি জরুরি।

## ৮. অ্যারিথমেটিক অপারেটর

```python
print(7 + 2)     # 9     যোগ
print(7 - 2)     # 5     বিয়োগ
print(5 * 2)     # 10    গুণ (অ্যাস্টেরিস্ক বা স্টার চিহ্ন)
print(4 / 2)     # 2.0   ভাগ → সবসময় float
print(5 % 2)     # 1     মডুলাস → ভাগশেষ
print(2 ** 3)    # 8     পাওয়ার → 2 টু দ্য পাওয়ার 3
print(2 ** 5)    # 32
```

| অপারেটর | নাম | উদাহরণ | ফল |
|---|---|---|---|
| `+` | যোগ (Addition) | `7 + 2` | `9` |
| `-` | বিয়োগ (Subtraction) | `7 - 2` | `5` |
| `*` | গুণ (Multiplication) | `5 * 2` | `10` |
| `/` | ভাগ (Division) | `4 / 2` | `2.0` |
| `//` | ফ্লোর ডিভিশন (ক্লাস ০১) | `7 // 2` | `3` |
| `%` | মডুলাস বা মড (Modulus) | `5 % 2` | `1` |
| `**` | পাওয়ার বা সূচক (Exponent) | `2 ** 3` | `8` |

### ৮.১ মডুলাস কেন দরকারি: জোড় না বিজোড়

`%` দেয় ভাগ করার পর যা **অবশিষ্ট থাকে**, অর্থাৎ ভাগশেষ। যেকোনো সংখ্যাকে ২ দিয়ে ভাগ করুন: ভাগশেষ `0` হলে সংখ্যাটা **জোড় (Even)**, নইলে **বিজোড় (Odd)**।

```python
x = 5

if x % 2 == 0:
    print("The number is even")
else:
    print("The number is odd")      # ← এটাই চলবে: 5 % 2 হলো 1
```

কম্পিটিটিভ প্রোগ্রামাররা এই ছোট প্রোগ্রাম দিয়েই শুরু করেন, আর এর ভেতরে একসাথে পাঁচটা ধারণা আছে: **ভেরিয়েবল**, **অ্যারিথমেটিক অপারেটর** (`%`), **কম্পারিজন অপারেটর** (`==`), **কন্ডিশন** (`if / else`) আর **ইনডেন্টেশন** (কোড ব্লক)।

### ৮.২ একটা স্টার নাকি দুটো

```python
print(5 * 2)     # 10   ← গুণ
print(5 ** 2)    # 25   ← পাওয়ার
```

একটা অক্ষরের জন্য অর্থ পুরো বদলে যায়। পাইথনের সিনট্যাক্স জানতেই হবে।

> **সূক্ষ্ম সংশোধন:** সঠিক শব্দটা **রিমেইন্ডার (Remainder)**, অর্থাৎ যা অবশিষ্ট থাকে; "রিমাইন্ডার (Reminder)" নয়। আর অনেক ক্যালকুলেটর ও স্প্রেডশিটে `^` মানে পাওয়ার, কিন্তু পাইথনে `^` সম্পূর্ণ আলাদা একটা অপারেটর (বিটওয়াইজ XOR): `5 ^ 2` দেয় `7`, `25` নয়। পাওয়ারের জন্য সবসময় `**`।

## ৯. কম্পারিজন অপারেটর

তুলনা একটা প্রশ্ন করে এবং উত্তর দেয় `True` অথবা `False`।

```python
print(2 == 2)    # True
print(2 != 2)    # False
print(2 > 3)     # False
print(2 >= 3)    # False
print(3 <= 3)    # True
print(2 < 3)     # True
```

| অপারেটর | অর্থ | উদাহরণ | ফল |
|---|---|---|---|
| `==` | সমান (Equal to) | `2 == 2` | `True` |
| `!=` | সমান নয় (Not equal to) | `2 != 2` | `False` |
| `>` | বড় (Greater than) | `2 > 3` | `False` |
| `<` | ছোট (Less than) | `2 < 3` | `True` |
| `>=` | বড় **অথবা** সমান | `3 >= 3` | `True` |
| `<=` | ছোট **অথবা** সমান | `3 <= 3` | `True` |

দুটো নিয়ম:

1. **`=` মান রাখে, `==` তুলনা করে।** `x = 5` মানে `x`-এ ৫ রাখা। `x == 5` মানে প্রশ্ন করা: "বাঁ পাশ কি ডান পাশের সমান?"
2. **দুই অক্ষরের অপারেটরে `=` সবসময় শেষে বসে:** `>=`, `<=`, `!=`। উল্টো করে লিখলে (`=>`, `=<`, `=!`) `SyntaxError`। পাইথন চেঁচিয়ে জানিয়ে দেবে। নতুনদের খুব প্রচলিত ভুল এটা।

## ১০. কন্ডিশন: if, elif, else

কন্ডিশন দিয়ে প্রোগ্রাম কোনো কিছু সত্য না মিথ্যা তা দেখে **ঠিক করে** কী করবে। কিওয়ার্ড তিনটা:

| কিওয়ার্ড | পড়ুন | কখন চলে |
|---|---|---|
| `if` | "যদি" | নিজের শর্ত `True` হলে |
| `elif` | "নইলে যদি" (else if-এর পাইথনি সংক্ষিপ্ত রূপ) | ওপরের সব শর্ত `False` **এবং** এটা `True` হলে |
| `else` | "অন্যথায়" | ওপরের কোনোটাই `True` না হলে |

### ১০.১ দুই শাখা: পাস না ফেল

কোর্সের সার্টিফিকেট পেতে ৬০% লাগে।

```python
pass_mark = 60
your_mark = 89

if your_mark >= pass_mark:
    print("You get a certificate")
else:
    print("You don't deserve a certificate yet. Practice more.")
```

সিনট্যাক্সের ধরন (লুপের মতোই): কিওয়ার্ড, শর্ত, **কোলন**, **ইনডেন্ট করা ব্লক**।

### ১০.২ তিন শাখা: `elif` যোগ

৫০–৫৯ পাওয়া মানুষটা খুব কাছে গিয়েছিলেন। কড়া কথার বদলে তাঁকে একটা উৎসাহের বার্তা দিই।

```python
pass_mark = 60
your_mark = 59

if your_mark >= pass_mark:
    print("You get a certificate")
elif your_mark >= 50 and your_mark < 60:
    print("So close (কানের পাশ দিয়ে গেছে)! Work a little harder.")
else:
    print("You don't deserve a certificate yet. Practice more.")
```

### ১০.৩ পাইথন কীভাবে এগোয়

পাইথন ওপর থেকে যাচাই করে এবং **শুধু প্রথম যে শাখাটা মেলে সেটাই** চালায়। তারপর পুরো কাঠামো থেকে বের হয়ে যায়। পরের শাখাগুলোর দিকে তাকায়ও না।

| `your_mark` | `>= 60`? | `>= 50 and < 60`? | কী চলে |
|---|---|---|---|
| `89` | ✅ True | *(যাচাই হয় না)* | "You get a certificate" |
| `59` | ❌ False | ✅ True এবং ✅ True | "So close!" |
| `49` | ❌ False | ❌ False এবং ✅ True → False | `else` → "Practice more" |

মনে রাখুন:

- `elif` **যতগুলো দরকার ততগুলো** দেওয়া যায়।
- `else` **ঐচ্ছিক**। শেষে একটা "অন্যথায়" চাইলে তবেই দিন।
- ওপরের `elif`-এ `your_mark < 60` অংশটা আসলে অপ্রয়োজনীয়: পাইথন ওই লাইনে পৌঁছানো মানেই নম্বর ৬০-এর নিচে। ক্লাসে এটা রাখা হয়েছিল `and` বোঝানোর জন্য। রাখলে কোনো ক্ষতি নেই।
- নম্বর ইউজারের কাছ থেকেও নেওয়া যায়: `your_mark = int(input("What mark did you obtain? "))`। কাস্ট করতে ভুলবেন না, কারণ `input()` সবসময় `str` দেয়।

### ১০.৪ ডেভঅপসে কন্ডিশন

**অ্যালার্ট।** সিপিইউ ৯০% মানে সমস্যা। কাউকে জানাতে হবে।

```python
cpu_usage = 93

if cpu_usage >= 90:
    print("ALERT: CPU is too high. Sending email...")
else:
    print("All normal. Nothing to do.")
```

**অ্যাক্সেস কন্ট্রোল।** রোল অনুযায়ী অনুমতি আলাদা।

```python
role = "collaborator"

if role == "admin":
    print("Full access")
elif role == "collaborator":
    print("Read-only access")
else:
    print("No access")
```

## ১১. লজিক্যাল অপারেটর

লজিক্যাল অপারেটর একাধিক শর্তকে জোড়া লাগায়।

| অপারেটর | নিয়ম | কখন `True` |
|---|---|---|
| `and` (এবং) | বাঁ পাশ ও ডান পাশ **দুটোই** সত্য হতে হবে | `True and True` |
| `or` (অথবা) | বাঁ পাশ বা ডান পাশের **যেকোনো একটা** সত্য হলেই চলবে | অন্তত এক পাশ `True` |

### ১১.১ একই নম্বরের উদাহরণে `and` বনাম `or`

`your_mark = 49` হলে:

```python
your_mark >= 50 and your_mark < 60
#    False      and     True         →  False   → else-এ চলে যায়
```

```python
your_mark >= 50 or your_mark < 60
#    False      or      True         →  True    → "So close!" প্রিন্ট হয়
```

একটা শব্দ বদলালেই বদলে যায় কে উৎসাহের বার্তা পাবে। `or` দিলে ৪৯ (এমনকি ১০) পেলেও শর্ত মিলে যায়, কারণ ডান পাশের `your_mark < 60` একাই সত্য। এই সমস্যার জন্য সেটা ভুল লজিক, তাই উদাহরণে `and` ব্যবহার করা হয়েছে।

### ১১.২ ট্রুথ টেবিল

| A | B | `A and B` | `A or B` |
|---|---|---|---|
| True | True | **True** | **True** |
| True | False | False | **True** |
| False | True | False | **True** |
| False | False | False | False |

> **ক্লাসের বাইরে একটু:** তৃতীয় একটা লজিক্যাল অপারেটর আছে, `not`, যা মান উল্টে দেয়: `not True` → `False`। আর পাইথনে রেঞ্জ এক লাইনে যাচাই করা যায়: `50 <= your_mark < 60`।

## ১২. ফাংশন

### ১২.১ বিল্ট-ইন ফাংশন: পাইথনের সাথে যা আসে

`print()`, `input()`, `len()`, `type()`, `sorted()`। পাইথন ইনস্টল করলে এগুলো সাথে চলে আসে, "বাক্সের ভেতরের স্ক্রু-ব্যাটারির মতো", জীবন সহজ করার জন্য। `print`-এর পেছনের অনেকগুলো লাইন কেউ একজন আগেই লিখে রেখেছেন, আপনাকে লিখতে হচ্ছে না।

**ফাংশন চেনার উপায়:** একটা নাম, তার পরে **প্যারেন্থেসিস (Parentheses)** অর্থাৎ প্রথম বন্ধনী `( )`, ভেতরে কিছু থাকুক বা না থাকুক: `print("hi")`, `len(x)`, `make_sum()`। পাইথনের বানানো হোক বা মানুষের, প্যারেন্থেসিসই চিহ্ন।

> **সূক্ষ্ম সংশোধন:** ক্লাসে `upper()`, `lower()` ও `sort()`-কে বিল্ট-ইন ফাংশনের তালিকায় ধরা হয়েছে। এগুলো আসলে **মেথড**: কোনো মানের সাথে জুড়ে থাকা ফাংশন, ডট দিয়ে ডাকা হয় (`name.upper()`, `items.sort()`)। প্যারেন্থেসিসের নিয়মটা এদের বেলাতেও খাটে। প্যারেন্থেসিস মানে কিছু একটা **কল** করা হচ্ছে: ফাংশন, মেথড, অথবা (অধ্যায় ১৪) ক্লাস।

### ১২.২ নিজের ফাংশন লেখা

নিজে যে ফাংশন বানান তাকে বলে **ইউজার-ডিফাইন্ড (User-defined)** বা কাস্টম ফাংশন।

```python
def make_sum():
    total = 3 + 2
    print(total)
```

গঠন:

```
def   make_sum  ( )  :
───   ────────  ───  ─
 │       │       │   └── কোলন → এরপর একটা কোড ব্লক
 │       │       └────── প্যারেন্থেসিস (প্যারামিটার বসে ভেতরে)
 │       └────────────── ফাংশনের নাম, স্নেক কেসে
 └────────────────────── কিওয়ার্ড: "define" (সংজ্ঞায়িত করো)
    total = 3 + 2     ← ইনডেন্ট করা ব্লক = ফাংশনের বডি
    print(total)
```

> **নামকরণ টিপস:** ক্লাসে ভেতরের ভেরিয়েবলের নাম ছিল `sum`। কাজ করে, কিন্তু `sum` নামে পাইথনের একটা বিল্ট-ইন ফাংশন আগে থেকেই আছে (`sum([1, 2, 3])` → `6`), আর একই নাম আবার ব্যবহার করলে সেটা ঢাকা পড়ে যায়। `total` নিরাপদ পছন্দ।

### ১২.৩ ফাংশনকে *কল* করতে হয়

ওপরের ফাইলটা চালান, **কিছুই হবে না**। কোনো আউটপুট নেই।

কেন? `print` আর `len`-এর কথা ভাবুন। পাইথনের ভেতরে এরা সবসময়ই আছে, কিন্তু আপনার কোড ব্যবহার না করা পর্যন্ত এরা কিছুই করে না। আপনার ফাংশনও তাই। `def` শুধু ফাংশনটা **ঘোষণা (Declare)** করে। চালাতে হলে নাম ও প্যারেন্থেসিস দিয়ে **কল (Call)** করতে হয়:

```python
make_sum()      # 5
make_sum()      # 5   ← যতবার খুশি কল করুন
```

### ১২.৪ প্যারামিটার ও আর্গুমেন্ট

সমস্যা: ওপরের ফাংশনটা শুধু ৩ আর ২-ই যোগ করতে পারে। ৪ আর ৫ যোগ করতে কি আরেকটা ফাংশন লিখবেন? আপনি চান **একবার** লিখে সংখ্যাগুলো লাখো বার বদলাতে।

```python
def make_sum(a, b):         # a ও b হলো প্যারামিটার
    total = a + b
    print(total)

make_sum(2, 3)              # 5    ← 2 ও 3 হলো আর্গুমেন্ট
make_sum(5, 6)              # 11
```

| টার্ম | কী | কোথায় থাকে |
|---|---|---|
| **প্যারামিটার (Parameter)** | একটা প্লেসহোল্ডার নাম | `def` লাইনে: `def make_sum(a, b)` |
| **আর্গুমেন্ট (Argument)** | আপনি যে আসল মান পাঠান | কল করার সময়: `make_sum(2, 3)` |

শিক্ষকের মত: কোনটা কোনটা তা নিয়ে ঘুম হারাম করার দরকার নেই; অনেকে শুধু "প্যারামস" বলেন। তবে ইন্টারভিউয়ের জন্য ওপরের টেবিলটাই সঠিক পার্থক্য।

`print`-ও এভাবেই কাজ করে। একবার লেখা হয়েছে, আর আপনি প্রতিবার ভিন্ন ভিন্ন জিনিস পাঠাচ্ছেন।

> **ক্লাসের বাইরে একটু: `print` বনাম `return`।** ওপরের ফাংশনগুলো উত্তরটা শুধু *দেখায়*। উত্তরটা **ফেরত দিতে** চাইলে, যাতে অন্য কোড সেটা ব্যবহার করতে পারে, ফাংশনে `return` লাগে:
>
> ```python
> def add(a, b):
>     return a + b
>
> result = add(2, 3)      # result-এর মান 5
> print(result * 10)      # 50
> ```
>
> যে ফাংশনে `return` নেই সে ফেরত দেয় `None`। অধ্যায় ৩.৭-এ `list.sort()` ঠিক এই কারণেই `None` দিয়েছিল।

### ১২.৫ ফাংশন কেন লিখি: পুনর্ব্যবহার

> **ফাংশন হলো পুনর্ব্যবহারযোগ্য (Reusable) একটা কোড ব্লক, যা একটা নির্দিষ্ট কাজ করে। একবার লিখুন, বারবার কল করুন।**

`print` পাইথন টিম একবারই লিখেছে। লাখ লাখ মানুষ সেটা কল করে। আপনার ফাংশনও একই কাজ করতে পারে: একই লাইন বারবার লেখা কমে, আর বাগ ঠিক করার জায়গা থাকে একটাই।

**এক ফাইল থেকে আরেক ফাইলে।** এক ফাইলে লেখা ফাংশন আরেক ফাইলে **ইম্পোর্ট (Import)** করা যায়। এভাবে ব্যবহৃত ফাইলকে বলে **মডিউল (Module)**:

```python
# একই ফোল্ডারের অন্য একটা ফাইলে
from user_function import make_sum

make_sum(10, 20)        # 30
```

(মডিউল ও প্যাকেজ ইনস্টল নিয়ে বিস্তারিত পরের ক্লাসে।)

### ১২.৬ ডেভঅপস উদাহরণ: ফাংশন + কন্ডিশন + কম্পারিজন

```python
def check_usage(usage):
    if usage >= 80:
        print("ALERT: server in danger!")
    else:
        print("All good. DevOps engineer can sleep.")

check_usage(90)     # ALERT: server in danger!
check_usage(70)     # All good. DevOps engineer can sleep.
```

ভাবুন, ফাংশনটা প্রতি মিনিটে নিজে নিজে চলছে আর চলতি ব্যবহারের মান পাচ্ছে। ৯০ পেলে অ্যালার্ট দেয়। ৭০ পেলে চুপ থাকে, ডেভঅপস ইঞ্জিনিয়ার "নাকে তেল দিয়ে" ঘুমান, রাত তিনটায় কাউকে উঠতে হয় না। ছোট্ট একটা উদাহরণে জোড়া লেগেছে **ফাংশন**, **প্যারামিটার**, **কন্ডিশন** আর **কম্পারিজন অপারেটর**। আসল প্রোগ্রাম এভাবেই টুকরো জুড়ে তৈরি হয়।

### ১২.৭ ভেরিয়েবল বনাম ফাংশন: নাউন বনাম ভার্ব

```python
memory = 60     # শুধু একটা মান ধরে রাখে; নিজে কিছু করতে পারে না
```

| | ভেরিয়েবল | ফাংশন |
|---|---|---|
| কাজ | মান **ধরে রাখে** | কোনো কাজ **করে** |
| ইংরেজি ব্যাকরণে | নাউন / অ্যাডজেক্টিভ (বিশেষ্য / বিশেষণ) | **ভার্ব (ক্রিয়া)** |
| উদাহরণ | `memory = 60` | `check_usage(60)` |

(ক্লাসের একটা প্রাসঙ্গিক কথা: সফটওয়্যার ইঞ্জিনিয়ারের কাছে **মেমোরি (Memory)** মানে **র‍্যাম (RAM)**। হার্ডডিস্কের জায়গা হলো **ডিস্ক (Disk)** ব্যবহার। দুটো গুলিয়ে ফেলবেন না।)

নাউন আর ভার্বের কথাটা মনে রাখুন। পরের অধ্যায় ঠিক এই দুটো দিয়েই তৈরি।

## ১৩. নামকরণের নিয়ম

নামে একাধিক শব্দ থাকলে মাঝে স্পেস দেওয়া যায় না। প্রচলিত স্টাইল ("কেস") চারটা:

| কেস | দেখতে | নামের কারণ | পাইথনে ব্যবহার |
|---|---|---|---|
| **স্নেক কেস (snake_case)** | `my_name` | সাপের মতো মাটি ঘেঁষে লম্বা | ✅ ভেরিয়েবল, ফাংশন, ফাইলের নাম |
| **ক্যামেল কেস (camelCase)** | `myName` | উটের পিঠের মতো মাঝখানে উঁচু | বৈধ, তবে এটা জাভা / জাভাস্ক্রিপ্টের অভ্যাস |
| **প্যাসকেল কেস (PascalCase)** | `MyName` | প্রতিটা শব্দ বড় হাতের অক্ষরে শুরু | ✅ ক্লাসের নাম |
| **কাবাব কেস (kebab-case)** | `my-name` | শিকে গাঁথা কাবাবের মতো | ❌ পাইথনের নামে ব্যবহার করা যায় না |

```python
def make_sum():         # ফাংশন → স্নেক কেস
total_price = 100       # ভেরিয়েবল → স্নেক কেস

class HumanSurvey:      # ক্লাস → প্যাসকেল কেস
```

> **সূক্ষ্ম সংশোধন:** ক্লাসে বলা হয়েছে স্ট্যান্ডার্ড মানতে "কাবাব কেস ব্যবহার করবেন না"। ব্যাপারটা তার চেয়েও কড়া: পাইথনে কাবাব কেস **অসম্ভব**। `my-name = 1` লিখলে পাইথন পড়ে "`my` বিয়োগ `name`", এবং `SyntaxError` দেয়। তবে পাইথন কোডের বাইরে কাবাব কেস অনেক দেখবেন: ইউআরএল, গিট ব্রাঞ্চের নাম, ডকার ইমেজের নাম, কুবারনেটিস রিসোর্সের নাম।

## ১৪. ক্লাস ও অবজেক্ট

এটা "পাইথন ক্লাসের ভেতরে পাইথনের ক্লাস"। আমাদের ক্লাসরুমের ক্লাস নয়, পাইথনের `class`।

### ১৪.১ প্রোগ্রাম সাজানোর দুই পদ্ধতি

একটা প্রোগ্রামে ৫০টা ফাংশন লাগলে আপনি একটার পর একটা ফাংশন লিখে যেতে পারেন। অথবা সম্পর্কিত ডাটা ও ফাংশনগুলোকে একসাথে গুছিয়ে **ক্লাস (Class)** বানাতে পারেন। দ্বিতীয় পদ্ধতিটাই **অবজেক্ট-ওরিয়েন্টেড প্রোগ্রামিং (Object-Oriented Programming বা OOP)**।

> **সূক্ষ্ম সংশোধন:** ক্লাসে প্রথম পদ্ধতিকে বলা হয়েছে "ফাংশনাল প্রোগ্রামিং", আর একজন স্টুডেন্ট বলেছিলেন "প্রসিডিউরাল"। স্টুডেন্টের শব্দটাই সঠিক: একটার পর একটা ফাংশন দিয়ে সাজানো প্রোগ্রাম হলো **প্রসিডিউরাল প্রোগ্রামিং (Procedural Programming)**। ("ফাংশনাল প্রোগ্রামিং" আলাদা, আরো বিশেষায়িত একটা ধারার নাম।) তাই মনে রাখার দুই পদ্ধতি: **প্রসিডিউরাল** এবং **অবজেক্ট-ওরিয়েন্টেড**।

### ১৪.২ ব্লুপ্রিন্টের ধারণা

**বাড়ি।** দাদা আপনাকে তিন কাঠা জমি দিয়ে গেছেন। আপনি খসড়া কাগজে এঁকে দিলেন কী চান: চারটা রুম, বড় একটা ড্রয়িং-ডাইনিং, প্রতি রুমে দুটো জানালা আর দুটো দরজা। কাগজটা দিলেন আর্কিটেক্ট বা সিভিল ইঞ্জিনিয়ারকে, তিনি বানালেন একটা **নকশা বা ব্লুপ্রিন্ট (Blueprint)**। সেই এক ব্লুপ্রিন্ট দিয়ে একই মাপের জমিতে হাজার হাজার বাড়ি বানানো যায়।

**গাড়ি।** ফোর্ড একটা থ্রি-হুইলার ডিজাইন করল: তিনটা চাকা (পেছনে দুটো, সামনে একটা), একটা ইঞ্জিন, একটা ফুয়েল সিস্টেম। ওই ডিজাইনটা ব্লুপ্রিন্ট। ফ্যাক্টরি সেটা দেখে গাড়ির পর গাড়ি বানায়।

**বঙ্গডেভে ভর্তি।** আপনি ভর্তি হন ইমেইল, পাসওয়ার্ড আর পেমেন্ট দিয়ে। ব্যাকএন্ডে প্রতি স্টুডেন্টের জন্য আলাদা পাইথন ফাইল নেই। আছে **একটাই** `Student` ব্লুপ্রিন্ট। প্রতিটা ভর্তিতে সেখান থেকে একটা নতুন স্টুডেন্ট রেকর্ড তৈরি হয়, আর এক ব্লুপ্রিন্ট থেকেই আসে হাজার হাজার স্টুডেন্ট।

**AWS।** EC2 কনসোলের পেছনে একটা ব্লুপ্রিন্ট আছে: "ইউজার এই এই অপশন বাছলে তাকে একটা মেশিন বানিয়ে দাও"। যে আসল মেশিনটা আপনি পান তার নাম **EC2 ইনস্ট্যান্স (Instance)**। শব্দটা কোথা থেকে এসেছে এখন বুঝতে পারছেন।

### ১৪.৩ তিনটা শব্দ ঠিকভাবে বোঝা

| টার্ম | অর্থ | বাড়ির উপমায় |
|---|---|---|
| **ক্লাস (Class)** | **ব্লুপ্রিন্ট**, নকশা | আর্কিটেক্টের ড্রয়িং |
| **অবজেক্ট (Object)** | ক্লাস থেকে বানানো **আসল জিনিস** | সত্যিকারের একটা বাড়ি |
| **ইনস্ট্যান্স (Instance)** | অবজেক্টেরই আরেক নাম: "ক্লাসের একটা ইনস্ট্যান্স" | "এই বাড়িটা ওই ব্লুপ্রিন্টের একটা ইনস্ট্যান্স" |
| **ইনস্ট্যানশিয়েট (Instantiate)** | ক্লাস থেকে অবজেক্ট তৈরি করা | বাড়ি বানানো |

> **সূক্ষ্ম সংশোধন:** ক্লাসে "অবজেক্ট" আর "ক্লাস" শব্দ দুটো একই অর্থে ব্যবহার হয়েছে ("ক্লাস = অবজেক্ট = ব্লুপ্রিন্ট", আর আসল জিনিস = "অবজেক্টের ইনস্ট্যান্স")। প্রচলিত সংজ্ঞা, যা ইন্টারভিউয়াররা আশা করেন:
> - **ক্লাস = ব্লুপ্রিন্ট।**
> - **অবজেক্ট = ইনস্ট্যান্স = ব্লুপ্রিন্ট থেকে বানানো আসল জিনিস।**
>
> তাই নিচের `noor` হলো **একটা অবজেক্ট**, এবং একইসাথে **`HumanSurvey` ক্লাসের একটা ইনস্ট্যান্স**। শব্দ দুটো একই জিনিসকে দুই দিক থেকে বর্ণনা করে।

### ১৪.৪ ক্লাসের ভেতরে কী থাকে: নাউন ও ভার্ব

থ্রি-হুইলারে ফিরে যাই:

```
wheels = 3            ┐
engine = 1            ├─ মান ধরে রাখে → ভেরিয়েবল (নাউন) → নাম: অ্যাট্রিবিউট
fuel_system = 1       ┘

switch_on()           ┐
switch_off()          ┴─ কিছু করে     → ফাংশন (ভার্ব)    → নাম: মেথড
```

সুইচ অন করলে ফুয়েল সিস্টেম চালু হয়, সেটা ইঞ্জিন চালায়, ইঞ্জিন চাকা ঘোরায়, গাড়ি দৌড়ায়। এটা একটা কাজ, তাই এটা ফাংশন।

| ক্লাসের ভেতরে | আসলে এটা… | ব্যাকরণে | উদাহরণ |
|---|---|---|---|
| **অ্যাট্রিবিউট (Attribute)** | ভেরিয়েবল | নাউন | `self.name`, `self.status` |
| **মেথড (Method)** | ফাংশন | ভার্ব | `introduce()`, `stop_server()` |

ক্লাসের ভেতরে আমরা সাধারণত ফাংশন না বলে **মেথড** বলি। "ফাংশন" বললে ভুল হয় না।

### ১৪.৫ ক্লাস লেখা

ক্লাস ০১-এর সেই জনশুমারি জরিপ, এবার ক্লাস আকারে:

```python
class HumanSurvey:
    def __init__(self, name, age, has_wife, kids):
        self.name = name
        self.age = age
        self.has_wife = has_wife
        self.kids = kids

    def introduce(self):
        print(f"I am {self.name}. I am {self.age} years old and I have {len(self.kids)} kids.")
```

টুকরো ধরে ধরে:

| অংশ | অর্থ |
|---|---|
| `class` | যে কিওয়ার্ড দিয়ে ক্লাস শুরু হয়, যেভাবে `def` দিয়ে ফাংশন শুরু হয়। |
| `HumanSurvey` | ক্লাসের নাম, **প্যাসকেল কেসে**: প্রতিটা শব্দ বড় হাতের অক্ষরে শুরু। |
| `:` + ইনডেন্টেশন | আবারও একটা কোড ব্লক। |
| `__init__` | **কনস্ট্রাক্টর (Constructor)**: একটা বিশেষ মেথড, নতুন অবজেক্ট তৈরি হলেই পাইথন এটা **নিজে থেকে** চালায়। দুই পাশে দুটো করে আন্ডারস্কোর ("ডান্ডার ইনিট")। |
| `self` | যে অবজেক্টটা তৈরি বা ব্যবহার হচ্ছে। নিচের নোট দেখুন। |
| `name, age, has_wife, kids` | প্যারামিটার: অবজেক্ট বানানোর সময় যে তথ্যগুলো দিতেই হবে। |
| `self.name = name` | "আমাকে যে `name` দেওয়া হলো, সেটা **এই অবজেক্টের গায়ে** জমা রাখো।" এভাবে জমা রাখা মানগুলোই **অ্যাট্রিবিউট**। |
| `introduce(self)` | একটা **মেথড**। `self`-এর মাধ্যমে অবজেক্টের নিজের ডাটা পড়ে। |

> **`self` নিয়ে সূক্ষ্ম সংশোধন:** ক্লাসে ব্যাখ্যা ছিল "`self` ক্লাসটাকেই বোঝায়"। আরো সঠিকভাবে বললে, `self` বোঝায় **নির্দিষ্ট সেই অবজেক্টটাকে (ইনস্ট্যান্স)** যেটা তৈরি বা ব্যবহার হচ্ছে, ক্লাসকে নয়। `noor.introduce()` কল করলে `self` *হলো* `noor`। `bob.introduce()` কল করলে `self` *হলো* `bob`। এভাবেই একটা মেথড হাজারটা অবজেক্টের কাজ করে, অথচ প্রত্যেকের ডাটা আলাদা থাকে। `self` আপনাকে পাঠাতে হয় না। পাইথন নিজেই বসিয়ে দেয়।

### ১৪.৬ অবজেক্ট (ইনস্ট্যান্স) তৈরি

একজন জরিপকর্মী বাড়ি বাড়ি যান। প্রতি বাড়িতে **একই ফর্ম** পূরণ হয় **ভিন্ন ডাটা** দিয়ে। ক্লাসকে ফাংশনের মতোই কল করা হয়, মানগুলো পাঠিয়ে:

```python
noor = HumanSurvey("Noor", 60, False, ["Liam", "Maya"])
bob = HumanSurvey("Bob", 45, True, [])

noor.introduce()        # I am Noor. I am 60 years old and I have 2 kids.
print(bob.name)         # Bob
```

- `noor` আর `bob` **একটাই** ক্লাস থেকে বানানো দুটো আলাদা **অবজেক্ট**।
- `noor.introduce()` একটা **মেথড** কল করে (প্যারেন্থেসিসসহ)।
- `bob.name` একটা **অ্যাট্রিবিউট** পড়ে (প্যারেন্থেসিস ছাড়া)।
- `introduce`-এর ভেতরে কোথাও "Noor" লেখা নেই। অবজেক্টটা যে নাম দিয়ে তৈরি, মেথড সেটাই তুলে নেয়।

### ১৪.৭ ডেভঅপস উদাহরণ: EC2 সার্ভার ক্লাস

```python
class EC2Server:
    def __init__(self, server_id, ip_address, instance_type):
        self.server_id = server_id
        self.ip_address = ip_address
        self.instance_type = instance_type      # t2.micro, t2.small, t2.large ...
        self.status = "running"                 # নতুন সার্ভার শুরুতেই running

    def start_server(self):
        self.status = "running"
        return f"Server {self.server_id} ({self.instance_type}) is running at {self.ip_address}"

    def stop_server(self):
        self.status = "stopped"


web_server = EC2Server("i-0a1b2c3d", "10.0.1.10", "t2.micro")
db_server = EC2Server("i-0e4f5a6b", "10.0.1.20", "t2.large")

print(web_server.start_server())
# Server i-0a1b2c3d (t2.micro) is running at 10.0.1.10

db_server.stop_server()
print(db_server.status)     # stopped
print(web_server.status)    # running   ← প্রতিটা অবজেক্টের status নিজস্ব
```

ব্লুপ্রিন্ট একটা, সার্ভার দুটো। ডাটাবেস সার্ভার বন্ধ করলে ওয়েব সার্ভারের কিছু হয় না।

একই কাজ আলাদা আলাদা ফাংশন আর ভেরিয়েবল দিয়েও *লেখা যেত*। ক্লাস দেয় আরো **পরিচ্ছন্ন** একটা উপায়: যে ডাটা আর যে কাজগুলো একসাথে থাকার কথা, সেগুলো একসাথেই থাকে।

### ১৪.৮ পাইথনে সবকিছুই অবজেক্ট

```python
x = "hello"
```

ভিএস কোডে `x.` লিখে সাজেশনের তালিকাটা দেখুন: `count`, `find`, `format`, `index`, `join`, `lower`, `upper`, `title`… এগুলো সবই **মেথড**, প্রতিটা স্ট্রিংয়ের সাথে থাকে।

```python
print(x.upper())        # HELLO
print(x.title())        # Hello
print(x.count("l"))     # 2
print(type(x))          # <class 'str'>
```

ক্লাস ০১-এর সেই `<class 'str'>` এবার পরিষ্কার হলো। `str` একটা **ক্লাস**, পাইথন টিমের লেখা একটা ব্লুপ্রিন্ট। `"hello"` তা থেকে বানানো একটা **অবজেক্ট**, যার নিজস্ব অ্যাট্রিবিউট ও মেথড আছে। সংখ্যা (`<class 'int'>`), লিস্ট (`<class 'list'>`), এমনকি ফাংশনের বেলাতেও তাই। পাইথনে সবকিছুই অবজেক্ট।

## ১৫. ক্লাসে যে প্রশ্নগুলো এসেছিল

**প্রশ্ন: `prod_ips + dev_ips` আর `append`, দুটোতেই তো একই রকম ফল এল। কখন কোনটা ব্যবহার করব?**
পছন্দ আপনার, তবে হাতে কী আছে তা দেখে:
- হাতে **দুটো লিস্ট** → `+` দিয়ে জোড়া।
- হাতে একটা লিস্ট আর **একটা আইটেম** → `append` (শেষে) বা `insert` (নির্দিষ্ট অবস্থানে)।
- `+` শুধু লিস্ট-টু-লিস্ট কাজ করে। `list + "string"` দিলে `TypeError`।

*বাড়তি একটা সতর্কতা:* `append` তার আর্গুমেন্টকে **একটামাত্র আইটেম** হিসেবে যোগ করে। লিস্টের ভেতরে লিস্ট `append` করলে লিস্টের **ভেতরে** আরেকটা লিস্ট ঢুকে যায়:

```python
prod_ips = ["10.0.1.10", "10.0.1.11"]
prod_ips.append(["10.0.2.20", "10.0.2.21"])
print(prod_ips)     # ['10.0.1.10', '10.0.1.11', ['10.0.2.20', '10.0.2.21']]   ← ৪টা নয়, ৩টা আইটেম
```

এক লিস্টের আইটেমগুলো আরেক লিস্টে নিজের জায়গাতেই ঢেলে দিতে চাইলে `extend()`: `prod_ips.extend(dev_ips)`।

**প্রশ্ন: লুপের ভেতরে অনেক লাইনের কাজ থাকলে? লিস্ট কম্প্রিহেনশনে কি তা হয়?**
কম্প্রিহেনশন ছোট লুপের জন্য। শেষে `if` দিয়ে ফিল্টার, অথবা `for`-এর আগে `if ... else` দিয়ে বাছাই যোগ করা যায়। এর বেশি হলে সাধারণ `for` লুপ লিখুন।

**প্রশ্ন: ডেভঅপসের দৃষ্টিতে শেল স্ক্রিপ্টিং আর পাইথন তো কাছাকাছি কাজ করে। একটার বদলে আরেকটা ব্যবহার করব?**
**শেল (Bash) স্ক্রিপ্ট** ব্যবহার করুন তার নিজের জায়গায়: কমান্ড চালানো আর টুলগুলোকে জোড়া লাগানো। কাজ যখন বেশি **অপারেশন-ইনটেনসিভ** (আসল লজিক, ডাটা প্রসেসিং, JSON, এপিআই), তখন **পাইথন**। আর এআই-এর যুগে একজন ডেভঅপস ইঞ্জিনিয়ারের জন্য পাইথন জানা অপরিহার্য।

> আগে নিজে চেষ্টা করুন। শুধু মিলিয়ে দেখার জন্য সমাধান খুলুন।

### সমস্যা ১ — জোড় না বিজোড়, ১ থেকে ১০

১ থেকে ১০ পর্যন্ত প্রতিটা সংখ্যা প্রিন্ট করুন, পাশে `even` অথবা `odd` লিখে।

*ইঙ্গিত:* `range(1, 11)` দেয় ১ থেকে ১০ পর্যন্ত সংখ্যা (stop মানটা অন্তর্ভুক্ত নয়)।

<details>
<summary>সমাধান দেখুন</summary>

```python
for number in range(1, 11):
    if number % 2 == 0:
        print(number, "even")
    else:
        print(number, "odd")
```

</details>

### সমস্যা ২ — রিইউনিয়নের লিস্ট

ব্যাচ ৪-এর ইমেইল: `["rahim@x.com", "karim@x.com"]`। ব্যাচ ৫-এর ইমেইল: `["sadia@x.com", "anis@x.com"]`। একটা সাজানো লিস্ট বানান, প্রিন্ট করুন, কতজন আমন্ত্রিত তা প্রিন্ট করুন, এবং `"anis@x.com"` আমন্ত্রিত কি না যাচাই করুন।

<details>
<summary>সমাধান দেখুন</summary>

```python
batch_4 = ["rahim@x.com", "karim@x.com"]
batch_5 = ["sadia@x.com", "anis@x.com"]

invite_list = batch_4 + batch_5
invite_list.sort()

print(invite_list)
print(len(invite_list))

if "anis@x.com" in invite_list:
    print("Anis is invited")
```

</details>

### সমস্যা ৩ — বেশি সিপিইউ-ওয়ালা সার্ভার

দেওয়া আছে `cpu_readings = [45.2, 91.5, 78.0, 95.1]`। শুধু ৯০ বা তার বেশি রিডিংগুলো নিয়ে নতুন একটা লিস্ট বানান। একবার `for` লুপ দিয়ে, একবার লিস্ট কম্প্রিহেনশন দিয়ে।

<details>
<summary>সমাধান দেখুন</summary>

```python
cpu_readings = [45.2, 91.5, 78.0, 95.1]

# for লুপ
high = []
for reading in cpu_readings:
    if reading >= 90:
        high.append(reading)
print(high)                                             # [91.5, 95.1]

# লিস্ট কম্প্রিহেনশন
high = [reading for reading in cpu_readings if reading >= 90]
print(high)                                             # [91.5, 95.1]
```

</details>

### সমস্যা ৪ — তিন স্তরের অ্যালার্ট ফাংশন

`check_cpu(usage)` লিখুন: ৯০ বা বেশি → `CRITICAL`, ৭০ থেকে ৮৯ → `WARNING`, অন্যথায় → `OK`। ৯৫, ৭৫ ও ৪০ দিয়ে কল করুন।

<details>
<summary>সমাধান দেখুন</summary>

```python
def check_cpu(usage):
    if usage >= 90:
        print("CRITICAL")
    elif usage >= 70:
        print("WARNING")
    else:
        print("OK")

check_cpu(95)   # CRITICAL
check_cpu(75)   # WARNING
check_cpu(40)   # OK
```

`elif`-এ `and usage < 90` লাগে না: `usage >= 90` মিথ্যা হলেই কেবল পাইথন ওখানে পৌঁছায়।

</details>

### সমস্যা ৫ — একটা `Student` ক্লাস

`name`, `email` ও `paid` (True/False) নিয়ে একটা `Student` ক্লাস বানান। সাথে একটা মেথড `show_status()`, যা প্রিন্ট করবে স্টুডেন্টের কোর্স অ্যাক্সেস আছে কি না। দুজন স্টুডেন্ট তৈরি করে দুজনের ওপরই মেথডটা কল করুন।

<details>
<summary>সমাধান দেখুন</summary>

```python
class Student:
    def __init__(self, name, email, paid):
        self.name = name
        self.email = email
        self.paid = paid

    def show_status(self):
        if self.paid:
            print(f"{self.name} has course access")
        else:
            print(f"{self.name} needs to complete payment")


rahim = Student("Rahim", "rahim@x.com", True)
sadia = Student("Sadia", "sadia@x.com", False)

rahim.show_status()     # Rahim has course access
sadia.show_status()     # Sadia needs to complete payment
```

</details>

## ১৮. ইন্টারভিউ কর্নার

**প্রশ্ন: `append()` আর `insert()`-এর পার্থক্য কী?**
`append(x)` লিস্টের শেষে `x` যোগ করে। `insert(i, x)` ইনডেক্স `i`-তে `x` বসায় এবং পরের আইটেমগুলোকে ডানে সরায়।

**প্রশ্ন: `remove()` আর `pop()`-এর পার্থক্য কী?**
`remove(x)` প্রথম যে আইটেমটা `x`-এর সমান সেটা মুছে দেয়, কিছু ফেরত দেয় না। `pop(i)` ইনডেক্স `i`-এর আইটেম মুছে দেয় (ইনডেক্স না দিলে শেষেরটা) এবং সেটা ফেরত দেয়।

**প্রশ্ন: `sort()` আর `sorted()`-এর পার্থক্য কী?**
`list.sort()` একটা মেথড, লিস্টকে নিজের জায়গায় সাজায় এবং `None` ফেরত দেয়। `sorted(iterable)` একটা বিল্ট-ইন ফাংশন, নতুন সাজানো লিস্ট ফেরত দেয়, মূলটা অপরিবর্তিত থাকে।

**প্রশ্ন: কোনো মান লিস্টে বা স্ট্রিংয়ে আছে কি না কীভাবে দেখবেন?**
`in` অপারেটর দিয়ে: `"x" in my_list`, `"err" in "error log"`। এটা বুলিয়ান ফেরত দেয়।

**প্রশ্ন: `for` লুপ কী?**
এমন একটা কাঠামো যা একটা সিকোয়েন্সের ওপর ইটারেট করে, প্রতিটা আইটেমের জন্য ইনডেন্ট করা ব্লকটা একবার চালায়, আর লুপ ভেরিয়েবলে চলতি আইটেমটা থাকে।

**প্রশ্ন: পাইথনে ইনডেন্টেশন কেন গুরুত্বপূর্ণ?**
পাইথন কোড ব্লক চিহ্নিত করতে ব্রেসের বদলে ইনডেন্টেশন ব্যবহার করে। `for`, `if`, `def` বা `class`-এর নিচে ইনডেন্ট করা লাইনগুলো তারই অংশ। ভুল বা অনুপস্থিত ইনডেন্টেশন মানে `IndentationError`।

**প্রশ্ন: লিস্ট কম্প্রিহেনশন কী?**
আগে থেকে থাকা সিকোয়েন্স থেকে এক লাইনে নতুন লিস্ট বানানোর উপায়: `[expression for item in sequence if condition]`।

**প্রশ্ন: `%` কী করে, কোথায় কাজে লাগে?**
ভাগের ভাগশেষ ফেরত দেয়। `n % 2 == 0` দিয়ে `n` জোড় কি না পরীক্ষা করা হয়।

**প্রশ্ন: `=` আর `==`-এর পার্থক্য কী?**
`=` ভেরিয়েবলে মান রাখে। `==` দুটো মান তুলনা করে `True` বা `False` দেয়।

**প্রশ্ন: `and` আর `or`-এর পার্থক্য কী?**
`and` তখনই সত্য, যখন দুটো শর্তই সত্য। `or` সত্য, যখন অন্তত একটা সত্য।

**প্রশ্ন: ফাংশন কী, কেন ব্যবহার করি?**
নামযুক্ত, পুনর্ব্যবহারযোগ্য একটা কোড ব্লক, যা একটা কাজ করে। `def` দিয়ে একবার ডিফাইন করে বহুবার কল করা যায়, চাইলে ভিন্ন ভিন্ন আর্গুমেন্ট দিয়ে। এতে পুনরাবৃত্তি কমে।

**প্রশ্ন: প্যারামিটার বনাম আর্গুমেন্ট?**
প্যারামিটার হলো ফাংশন ডেফিনিশনের ভেরিয়েবল নাম। আর্গুমেন্ট হলো ফাংশন কল করার সময় পাঠানো আসল মান।

**প্রশ্ন: ক্লাস কী? অবজেক্ট কী?**
ক্লাস একটা ব্লুপ্রিন্ট, যা অ্যাট্রিবিউট (ডাটা) ও মেথড (আচরণ) নির্ধারণ করে। অবজেক্ট, যাকে ইনস্ট্যান্সও বলে, সেই ক্লাস থেকে তৈরি একটা বাস্তব জিনিস। এক ক্লাস থেকে বহু অবজেক্ট বানানো যায়।

**প্রশ্ন: `__init__` কী?**
কনস্ট্রাক্টর (ইনিশিয়ালাইজার) মেথড। অবজেক্ট তৈরি হলে পাইথন এটা নিজে থেকেই কল করে, আর এটা অবজেক্টের অ্যাট্রিবিউটগুলো সেট করে।

**প্রশ্ন: `self` কী?**
ক্লাসের মেথডের ভেতরে চলতি অবজেক্টের রেফারেন্স। এর মাধ্যমে প্রতিটা অবজেক্ট নিজের অ্যাট্রিবিউট পড়তে ও বদলাতে পারে।

**প্রশ্ন: শেল স্ক্রিপ্টের বদলে কখন পাইথন বেছে নেবেন?**
কমান্ড চালানো ও সাধারণ অটোমেশনের জন্য শেল আদর্শ। কাজে যখন আসল লজিক, ডাটা স্ট্রাকচার, JSON, এপিআই থাকে, কিংবা কোডটা রক্ষণাবেক্ষণ ও পুনর্ব্যবহার করতে হয়, তখন পাইথনই ভালো পছন্দ।

## ১৯. পরিভাষা (Glossary)

| ইংরেজি টার্ম | বাংলা অর্থ | প্রসঙ্গ / ব্যাখ্যা |
|---|---|---|
| **Algorithm** | অ্যালগরিদম, কর্মপদ্ধতি | যে ধাপগুলো দিয়ে একটা কাজ সম্পন্ন হয়। |
| **`and` / `or`** | এবং / অথবা | লজিক্যাল অপারেটর: দুই পাশই সত্য / অন্তত এক পাশ সত্য। |
| **Append** | শেষে যোগ করা | লিস্টের শেষে একটা আইটেম বসানো। |
| **Argument** | আর্গুমেন্ট, প্রেরিত মান | ফাংশন কল করার সময় পাঠানো আসল মান। |
| **Arithmetic operator** | গাণিতিক অপারেটর | `+ - * / // % **`। |
| **Ascending / Descending** | ঊর্ধ্বক্রম / অধঃক্রম | ছোট → বড় (A → Z) / বড় → ছোট (Z → A)। |
| **Attribute** | অ্যাট্রিবিউট, বৈশিষ্ট্য | অবজেক্টের নিজস্ব ভেরিয়েবল (`self.name`)। |
| **Block of code** | কোড ব্লক | `for`, `if`, `def` বা `class`-এর অধীনে ইনডেন্ট করা লাইনগুলো। |
| **Blueprint** | নকশা, ব্লুপ্রিন্ট | যে ডিজাইন থেকে আসল জিনিস বানানো হয়; ক্লাস ঠিক তাই। |
| **Built-in function** | অন্তর্নির্মিত ফাংশন | পাইথনের সাথেই আসে (`print`, `len`, `sorted`)। |
| **Call** | কল করা, ডাকা | নাম ও প্যারেন্থেসিস লিখে ফাংশন চালানো। |
| **camelCase** | ক্যামেল কেস | নামকরণ স্টাইল: `myName`। |
| **Class** | ক্লাস, শ্রেণি | অবজেক্ট তৈরির ব্লুপ্রিন্ট। |
| **Comparison operator** | তুলনামূলক অপারেটর | `== != > < >= <=`; ফল `True` বা `False`। |
| **Concatenation** | সংযুক্তকরণ, জোড়া লাগানো | `+` দিয়ে দুটো লিস্ট (বা দুটো স্ট্রিং) জোড়া। |
| **Condition** | শর্ত | `True` বা `False` হয় এমন এক্সপ্রেশন, যা দিয়ে ঠিক হয় কী চলবে। |
| **Constructor (`__init__`)** | কনস্ট্রাক্টর, নির্মাতা মেথড | অবজেক্ট তৈরি হলে নিজে থেকে চলে। |
| **Data manipulation** | ডাটা ম্যানিপুলেশন, উপাত্ত পরিবর্তন | জমা থাকা ডাটা যোগ, আপডেট বা মুছে ফেলা। |
| **`def`** | ডিফাইন, সংজ্ঞায়িত করা | ফাংশন তৈরির কিওয়ার্ড। |
| **`elif`** | নইলে যদি | আগের শর্তগুলো না মিললে যাচাই হওয়া বাড়তি শর্ত। |
| **Empty list (`[]`)** | খালি লিস্ট | কোনো আইটেম নেই, পরে ভরা হবে। |
| **Indentation** | ইনডেন্টেশন, লাইনের শুরুর ফাঁক | কোড ব্লক চিহ্নিত করে (স্ট্যান্ডার্ড: ৪ স্পেস)। |
| **Indexing** | ইনডেক্সিং | অবস্থান দিয়ে একটা আইটেম পড়া: `lst[1]`। |
| **Instance** | ইনস্ট্যান্স, দৃষ্টান্ত | ক্লাস থেকে তৈরি একটা অবজেক্ট। |
| **Iterate / Traverse** | ইটারেট / ট্রাভার্স, একে একে ঘুরে দেখা | সংগ্রহের প্রতিটা আইটেমে একবার করে যাওয়া। |
| **Iteration** | ইটারেশন, আবর্তন | লুপের একেকটা রাউন্ড। |
| **JSON** | জেসন | JavaScript Object Notation: কী-ভ্যালু ডাটার টেক্সট ফরম্যাট। |
| **kebab-case** | কাবাব কেস | নামকরণ স্টাইল: `my-name`। পাইথনের নামে অবৈধ। |
| **Keyword** | কিওয়ার্ড, সংরক্ষিত শব্দ | পাইথনের নিজের জন্য রাখা শব্দ (`for`, `in`, `if`, `def`, `class`)। |
| **List comprehension** | লিস্ট কম্প্রিহেনশন | লুপ থেকে এক লাইনে লিস্ট বানানোর সিনট্যাক্স। |
| **Logical operator** | যৌক্তিক অপারেটর | `and`, `or`, `not`। |
| **Loop** | লুপ, পুনরাবৃত্তি | যে কাঠামো একটা কোড ব্লক বারবার চালায় (`for`, `while`)। |
| **Loop variable** | লুপ ভেরিয়েবল | `for` লুপে চলতি আইটেম ধরে রাখা নাম। |
| **Method** | মেথড | অবজেক্টের নিজস্ব ফাংশন, ডট দিয়ে ডাকা হয়। |
| **Module** | মডিউল | যে পাইথন ফাইলের কোড অন্য ফাইলে ইম্পোর্ট করা যায়। |
| **Modulus (`%`)** | মডুলাস, ভাগশেষ অপারেটর | ভাগের ভাগশেষ ফেরত দেয়। |
| **`None`** | কিছুই না | পাইথনের "শূন্যতা" মান; ফাংশন কিছু ফেরত না দিলে এটা পাওয়া যায়। |
| **Object** | অবজেক্ট, বস্তু | ক্লাস থেকে তৈরি আসল জিনিস; ইনস্ট্যান্সেরই আরেক নাম। |
| **OOP** | অবজেক্ট-ওরিয়েন্টেড প্রোগ্রামিং | ক্লাস ও অবজেক্ট ঘিরে কোড সাজানোর পদ্ধতি। |
| **Parameter** | প্যারামিটার | ফাংশন ডেফিনিশনের প্লেসহোল্ডার নাম। |
| **PascalCase** | প্যাসকেল কেস | নামকরণ স্টাইল: `MyName`। ক্লাসের নামে ব্যবহৃত। |
| **Pop** | পপ, বের করে আনা | অবস্থান ধরে আইটেম সরানো ও ফেরত দেওয়া। |
| **Procedural programming** | প্রসিডিউরাল প্রোগ্রামিং | ফাংশনের পর ফাংশন দিয়ে প্রোগ্রাম সাজানো। |
| **Remainder** | ভাগশেষ | ভাগ করার পর যা অবশিষ্ট থাকে। |
| **`return`** | ফেরত দেওয়া | ফাংশন থেকে কলারের কাছে মান ফেরত পাঠায়। |
| **`self`** | নিজে | ক্লাসের মেথডের ভেতরে চলতি অবজেক্ট। |
| **Slicing** | স্লাইসিং, টুকরো কাটা | রেঞ্জ দিয়ে ছোট লিস্ট নেওয়া: `lst[1:3]`। |
| **snake_case** | স্নেক কেস | নামকরণ স্টাইল: `my_name`। পাইথনে ভেরিয়েবল ও ফাংশনের স্ট্যান্ডার্ড। |
| **Sorting** | সর্টিং, ক্রমানুসারে সাজানো | আইটেমগুলোকে ক্রমে সাজানো। |
| **Stack** | স্ট্যাক, স্তূপ | যেখানে শেষে রাখা জিনিস সবার আগে বের হয়। |
| **Substring** | সাবস্ট্রিং, উপ-স্ট্রিং | বড় স্ট্রিংয়ের ভেতরের ছোট স্ট্রিং। |
| **User-defined function** | ব্যবহারকারীর তৈরি ফাংশন | যে ফাংশন আপনি নিজে লেখেন। |
| **`while` loop** | হোয়াইল লুপ | শর্ত সত্য থাকা পর্যন্ত চলতে থাকে। |
