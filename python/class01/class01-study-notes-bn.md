## ১. বড় ছবি: কেন প্রোগ্রাম লিখি

ক্লাস শুরু হয়েছিল একজন মানুষের একটা জরিপ দিয়ে: নাম, বয়স, পেশা, বিবাহিত কি না, স্পাউসের নাম, সন্তান, ঠিকানা, মোবাইল নম্বর, পরিবারের সদস্য সংখ্যা, বার্ষিক আয়। পরিসংখ্যান ব্যুরো কোটি কোটি টাকা খরচ করে বাড়ি বাড়ি লোক পাঠিয়ে ঠিক এই ধরনের তথ্যই সংগ্রহ করে।

এভাবে সংগ্রহ করা সবকিছুই **ডাটা (Data)**। ছবি, ভিডিও, এই ক্লাসের রেকর্ডিং, কর্মীদের তথ্য, হিসাবের খাতা, ট্যাক্সের ফাইল, সবই ডাটা। একজন ডেভঅপস ইঞ্জিনিয়ারের প্রতিদিনের ডাটা দেখতে এরকম:

| বাস্তব জিনিস | উদাহরণ মান (Value) |
|---|---|
| আইপি অ্যাড্রেস (IP Address) | `192.168.1.50` |
| সিপিইউ ব্যবহার (CPU Usage) | `75.1` (%) |
| ডকার সার্ভিসের অবস্থা (Status) | `active` |
| `pwd` / `ls` কমান্ডের আউটপুট | একটা ফোল্ডারের পাথ, ফাইলের তালিকা |

পুরো ক্লাস যে ধারণার শিকলের ওপর দাঁড়িয়ে:

```
র ডাটা  →  সাজানো-গোছানো (Structured)  →  ডাটাবেস / মেমোরিতে সংরক্ষণ
                         ↑
             কাজটা করে একটি প্রোগ্রাম (নির্দেশনা)
                         ↑
       যা লেখা হয় প্রোগ্রামিং ল্যাঙ্গুয়েজে (যেমন পাইথন)
                         ↑
        চলে একটি কম্পিউটারে (যা কিছু কম্পিউট করতে পারে)
```

- **ডাটাবেস (Database):** একটা "বাক্স", যা আপনার ডাটা ধরে রাখে এবং দরকারের সময় ফেরত দেয়। এনআইডি বা পাসপোর্ট স্ক্যান করলেই চোদ্দগুষ্টির খতিয়ান বের হয়ে আসে। এটাই ডাটাবেসের কাজ।
- হাতে-কলমে (Manually) ডাটা সাজানো সম্ভব, কিন্তু পছন্দের উপায় হলো **প্রোগ্রাম (Program)**।
- **কম্পিউটার (Computer):** যা কিছু গণনা (Compute) করতে পারে: ল্যাপটপ, সার্ভার, স্মার্টফোন।

## ২. প্রোগ্রামিং ল্যাঙ্গুয়েজ কী

শিক্ষক জাপানি ভাষায় একটা বাক্য বলে জিজ্ঞেস করলেন কেউ বুঝেছে কি না। কেউ বোঝেনি। মানুষের ভাষা নিয়ে কম্পিউটারেরও একই সমস্যা।

> **প্রোগ্রামিং ল্যাঙ্গুয়েজ (Programming Language) হলো এমন একটি ভাষা যা কম্পিউটার বা মেশিন বুঝতে পারে, যাতে সে আমাদের নির্দেশনা প্রসেস (Process) ও এক্সিকিউট (Execute, অর্থাৎ কার্যকর) করতে পারে।**

**ক্লাসের প্রমাণ:** লিনাক্স/ব্যাশ (Bash) টার্মিনালে সরাসরি `2 + 2` লিখলে কাজ করে না। ব্যাশ একটা শেল (Shell), ক্যালকুলেটর না, তাই নির্দেশটা সে বোঝে না। আগে পাইথন ইন্টারপ্রেটার চালু করুন (`python3`), তারপর একই `2 + 2` লিখলে উত্তর আসে `4`। কম্পিউটারকে একটা ভাষা দিলেই সে আপনাকে বুঝতে পারে।

### ইনপুট ও আউটপুট (Input / Output বা I/O)

কম্পিউটারের সাথে যেকোনো কাজ মানেই **ইনপুট → প্রসেসিং → আউটপুট**।

| আপনি দিচ্ছেন (ইনপুট) | কম্পিউটার ফেরত দিচ্ছে (আউটপুট) |
|---|---|
| `2 + 2` | `4` |
| `print("Hello there")` | স্ক্রিনে `Hello there` |
| কিবোর্ডে টাইপ, মাউসে ক্লিক | প্রোগ্রাম যা করে |

আরো যেসব ভাষার নাম শুনবেন: C++, C#, Java, JavaScript, PHP (লারাভেল বা Laravel হলো PHP-এর একটা *ফ্রেমওয়ার্ক (Framework)*, আলাদা ভাষা নয়)। এই কোর্সে আমরা শিখছি **পাইথন (Python)**, পৃথিবীর সবচেয়ে জনপ্রিয় ভাষাগুলোর একটি।

## ৩. পাইথনের পরিচয়

"পাইথন সহজ, ইংরেজির মতো" কথাটা সত্য, কিন্তু ইন্টারভিউতে এটা দুর্বল উত্তর। একজন ইঞ্জিনিয়ার পাইথনকে বর্ণনা করবেন তার **টেকনিক্যাল বৈশিষ্ট্য** দিয়ে:

### ৩.১ হাই-লেভেল ল্যাঙ্গুয়েজ (High-level Language)

| স্তর | অর্থ | উদাহরণ |
|---|---|---|
| **লো-লেভেল (Low-level)** | হার্ডওয়্যারের ("লোহা-লক্কড়") খুব কাছাকাছি কাজ করে; মেমোরি ও সিপিইউর খুঁটিনাটি নিজেকে সামলাতে হয় | Assembly, C (আংশিক) |
| **হাই-লেভেল (High-level)** | হার্ডওয়্যার থেকে দূরে থাকে, সাধারণ ইংরেজির কাছাকাছি পড়া যায়; মেশিনের খুঁটিনাটি ভাষা নিজেই সামলায় | Python, JavaScript |

"হাই-লেভেল" মানে **"এলিট" বা "বড়লোক" নয়**। শুধু বোঝায় ভাষাটা হার্ডওয়্যার থেকে কত দূরে বসে কাজ করে।

### ৩.২ ডাইনামিক্যালি টাইপড (Dynamically Typed)

অনেক ভাষায় টাইপ নিজে বলে দিতে হয়:

```c
int x = 2;        // C / Java স্টাইল: টাইপ নিজে লিখে দিতে হয়
```

পাইথনে শুধু লিখলেই হয়:

```python
x = 2             # পাইথন নিজেই বুঝে নেয় এটা int
name = "Noor"     # ...আর এটা str
```

পাইথন প্রতিটি মানের টাইপ **রানটাইমে (Runtime), অর্থাৎ চলার সময়ে** নিজেই শনাক্ত করে ("অন দ্য ফ্লাই")। এটাই *ডাইনামিক্যালি টাইপড* কথার অর্থ।

### ৩.৩ একসাথে কম্পাইলড ও ইন্টারপ্রেটেড (Compiled and Interpreted)

**ইন্টারপ্রেটার (Interpreter)** মানে **দোভাষী**, যেমন কেউ আপনার বাংলা কথা ফরাসিতে অনুবাদ করে দেয়।

`python3 my_program.py` চালালে আসলে যা ঘটে (CPython-এ, যা পাইথনের স্ট্যান্ডার্ড সংস্করণ):

1. **কম্পাইল ধাপ (Compile):** পাইথন *পুরো ফাইলটা* পড়ে সেটাকে **বাইটকোড (Bytecode)**-এ রূপান্তর করে। এটা একটা মাঝামাঝি রূপ (কখনো কখনো `__pycache__/` ফোল্ডারে `.pyc` ফাইল হিসেবে জমা থাকে)।
2. **ইন্টারপ্রেট ধাপ (Interpret):** **পাইথন ভার্চুয়াল মেশিন (Python Virtual Machine বা PVM)** সেই বাইটকোড **ওপর থেকে নিচে, এক স্টেটমেন্ট করে** চালায়।

এজন্যই ইন্টারভিউয়ের উত্তর: **"পাইথন একসাথে কম্পাইলড এবং ইন্টারপ্রেটেড।"** শিক্ষক একটা কৌশলও শিখিয়েছেন: এরকম টার্ম ইচ্ছা করেই ব্যবহার করুন। ইন্টারভিউয়ার তখন ব্যাখ্যা চাইবেন, আর যে প্রশ্নের উত্তর আপনি ভালো জানেন সেটা এলে বল আপনার কোর্টেই থাকে।

> **সূক্ষ্ম সংশোধন:** ক্লাসে সহজ করার জন্য বাইটকোডকে "মেশিন কোড" বলা হয়েছে। প্রকৃতপক্ষে বাইটকোড সরাসরি সিপিইউর মেশিন কোড **নয়**। এটা পাইথন ভার্চুয়াল মেশিনের জন্য তৈরি নির্দেশনা, আর PVM সেটা দিয়ে আসল হার্ডওয়্যার চালায়। প্রথম ক্লাসের জন্য "পাইথন আমাদের ইংরেজির মতো কোডকে মেশিন চালাতে পারে এমন কিছুতে অনুবাদ করে" ধারণাটাই যথেষ্ট।

### ৩.৪ কেস-সেনসিটিভ (Case-sensitive)

পাইথনের কাছে বড় হাতের (Uppercase) আর ছোট হাতের (Lowercase) অক্ষর আলাদা।

```python
x = "Noor"
y = "noor"
print(x == y)   # False — "N" আর "n" আলাদা অক্ষর

age = 60
Age = 61        # `age` থেকে সম্পূর্ণ আলাদা একটা ভেরিয়েবল
```

`==` মানে **"সমান কি না?"** (তুলনা, যার উত্তর `True`/`False`)। একটা `=` মানে **"এই মানটা রাখো"** (অ্যাসাইনমেন্ট, Assignment)। দুটো গুলিয়ে ফেলবেন না।

### ৩.৫ ওপর থেকে নিচে, এক লাইন করে চলে

```python
# This is a python program      ← কমেন্ট: বাদ যাবে
                                 ← ফাঁকা লাইন: কিছু করার নেই
print("line 1")                  ← ১ম চলবে
                                 
print("line 3")                  ← ২য় চলবে (লেবেলটা তো শুধু টেক্সট!)
                                 
print("line 2")                  ← ৩য় চলবে
x = 3                            ← ৪র্থ: মেমোরিতে 3 রাখে, কিছু প্রিন্ট করে না
```

আউটপুট:
```
line 1
line 3
line 2
```

আপনার টেক্সটে কী *লেখা আছে* তাতে পাইথনের কিছু যায় আসে না। সে ফাইলের **লাইনের ক্রম** মেনে চলে।

### ৩.৬ কমেন্ট (Comment)

**কমেন্ট** হলো মানুষের জন্য লেখা নোট। পাইথন এটা উপেক্ষা করে।

```python
# এই পুরো লাইনটা একটা কমেন্ট
port = 22   # লাইনের শেষেও কমেন্ট দেওয়া যায়
```

- যে লাইন কমেন্ট করতে চান তার শুরুতে `#` দিন।
- **ভিএস কোড শর্টকাট:** লাইনগুলো সিলেক্ট করে **`Ctrl + /`** চাপুন (ম্যাকে `Cmd + /`)। একবারে সব কমেন্ট বা আনকমেন্ট হয়ে যাবে।

## ৪. পাইথন সেটআপ ও চালানো

### ৪.১ পাইথন ইনস্টল আছে কি না দেখুন

```bash
python3 --version      # লিনাক্স / ম্যাক
python --version       # উইন্ডোজ (অথবা: py --version)
which python3          # লিনাক্স / ম্যাক: কোথায় ইনস্টল আছে?
```

দুটো ড্যাশ: `--version`। কোনো টুলে `-v`, কোনোটায় `--version`, কোনোটায় কোনোটাই না। টুলভেদে আলাদা, তাই সন্দেহ হলে `--help` দেখে নিন।

না থাকলে **python.org → Downloads** থেকে নামিয়ে নিন। সাইটটা নিজেই আপনার অপারেটিং সিস্টেম (উইন্ডোজ / ম্যাক / লিনাক্স) চিনে নেয়। কম্পিউটারে সব ভাষা আগে থেকে দেওয়া থাকে না, কারণ তাতে জায়গা নষ্ট হবে।

### ৪.২ ঝটপট প্র্যাকটিস বনাম ইঞ্জিনিয়ারের পদ্ধতি

- **ঝটপট প্র্যাকটিস:** python.org-এর অনলাইন শেল, অথবা টার্মিনালে `python3` লিখে ইন্টারঅ্যাক্টিভ **REPL** (`>>>` প্রম্পট) খুলুন। এক লাইনের জিনিস পরখ করতে ভালো।
- **ইঞ্জিনিয়ারের পদ্ধতি** (এই কোর্সে আমরা যা করব): একটা প্রজেক্ট ফোল্ডার, একটা `.py` ফাইল, একটা এডিটর, আর টার্মিনাল থেকে চালানো। শিক্ষকের ভাষায়: *"নাচতে নেমে ঘোমটা দিয়ে লাভ নেই।"* সফটওয়্যার ইঞ্জিনিয়াররা যেভাবে কাজ করেন, সেভাবেই করুন। শর্টকাটের জায়গা নেই।

## ৫. ডাটা, ডাটা স্ট্রাকচার ও অ্যালগরিদম

| টার্ম | সহজ সংজ্ঞা |
|---|---|
| **ডাটা (Data)** | কম্পিউটারের মেমোরিতে রাখা কাঁচা তথ্য, যা দিয়ে প্রোগ্রাম কাজ করে। |
| **ডাটা ম্যানিপুলেশন (Data Manipulation)** | রাখা ডাটা বদলানো: যেমন নূর ভাইয়ের বয়স ৬০ থেকে ৬২ করা, বা কোনো রেকর্ড মুছে ফেলা। |
| **ডাটা স্ট্রাকচার (Data Structure)** | ডাটাকে **সাজানো (Organise), ব্যবস্থাপনা (Manage), সংরক্ষণ (Store) ও ব্যবহার (Access)** করার একটা বিশেষ কাঠামো। র ডাটাকে গুছিয়ে রাখলে দরকারের সময় দ্রুত তথ্য বের করা যায়। |
| **অ্যালগরিদম (Algorithm)** | একটা কাজ শেষ করতে যে **ধাপগুলো (Steps)** অনুসরণ করা হয়। |

শুধু ডাটা রেখে দিলেই হবে না। কাল নূর ভাইয়ের বয়স লাগলে সেটা **চট করে বের করতে**, **আপডেট করতে** বা **মুছতে** পারতে হবে। ভালো ডাটা স্ট্রাকচার ঠিক এটাই দেয়।

**অ্যালগরিদম, ভয় ছাড়া।** দুটো সংখ্যা যোগ করাটাও একটা অ্যালগরিদম:

```python
x = 2          # ধাপ ১
y = 3          # ধাপ ২
z = x + y      # ধাপ ৩
print(z)       # ধাপ ৪  → 5
```

"অ্যালগরিদম" শুনলে মাথা ঘোরে, কিন্তু এটা আসলে রান্নার রেসিপির মতো: ধাপ ১, ধাপ ২, ধাপ ৩, কাজ শেষ।

ডাটা স্ট্রাকচার শিখতে হলে আগে **ডাটা টাইপ** (অনুচ্ছেদ ৭) জানতে হবে, আর ডাটা টাইপ ব্যবহার করতে লাগবে **ভেরিয়েবল**।

## ৬. ভেরিয়েবল

> **চলক বা ভেরিয়েবল (Variable) হলো একটা নাম, যা একটা মান (Value) ধরে রাখে, যাতে পরে সেই মান বারবার ব্যবহার করা যায়।**

নিজের নামের কথা ভাবুন। কেউ "নূর ভাই, কেমন আছেন?" বললেই নূর ভাই বোঝেন তাঁকে ডাকা হচ্ছে। নামটা মানুষটার দিকে ইঙ্গিত করে। ঠিক তেমনি ভেরিয়েবলের নাম মেমোরিতে থাকা একটা মানের দিকে ইঙ্গিত করে।

```python
name = "Noor"
age = 62
married = True
```

গঠন:

```
  age    =    62
  ───    ─    ──
  │      │    └── ভেরিয়েবলের মান (VALUE), ডান পাশে
  │      └─────── অ্যাসাইনমেন্ট অপারেটর ("=" চিহ্ন)
  └────────────── ভেরিয়েবলের নাম (NAME), বাম পাশে
```

**স্টাইলের নিয়ম (বেস্ট প্র্যাকটিস, PEP 8):** `=`-এর **দুই পাশে একটা করে স্পেস** দিন। `x=20` নয়, লিখুন `x = 20`। দুটোই চলবে, কিন্তু দ্বিতীয়টাই স্ট্যান্ডার্ড।

### ভেরিয়েবল কেন: পুনর্ব্যবহার (Reuse)

```python
name = "Noor"
age = 60

print(f"My name is {name} and my age is {age}")
# ... ২০০ লাইন পরে ...
print(f"{name} is {age} years old")
```

মান **একবার** রাখুন, **যতবার খুশি** ব্যবহার করুন। বয়স বদলালে এক জায়গায় বদলালেই হবে। না হলে সব জায়গায় `"Noor"` আর `60` বারবার টাইপ করতে হতো, যা ধীর এবং ভুলের সম্ভাবনায় ভরা।

## ৭. ডাটা টাইপ

একই মানুষের জরিপের সব উত্তর এক *জাতের* ডাটা নয়। `"Noor"` হলো লেখা, `62` হলো সংখ্যা, "বিবাহিত?" হলো হ্যাঁ/না। পাইথনকে জানতে হয় সে কোন জাতের ডাটা নিয়ে কাজ করছে। এজন্যই **ডাটা টাইপ (Data Type)**।

যেকোনো মানের টাইপ দেখতে বিল্ট-ইন ফাংশন `type()` ব্যবহার করুন:

```python
type("hello")    # <class 'str'>
type(60)         # <class 'int'>
type(12.3)       # <class 'float'>
type(4 > 6)      # <class 'bool'>
```

(আউটপুটে `class` শব্দ দেখে এখন চিন্তা করবেন না। পাইথনে সবকিছুই *অবজেক্ট (Object)*, সেটা পরের কোনো ক্লাসের বিষয়।)

### ৭.১ এক নজরে

| টাইপ | সংক্ষিপ্ত নাম | কী রাখে | কীভাবে লেখে | সাধারণ উদাহরণ | ডেভঅপস উদাহরণ |
|---|---|---|---|---|---|
| স্ট্রিং (String) | `str` | লেখা বা টেক্সট | উদ্ধৃতিচিহ্নের ভেতরে | `"Alice Smith"` | `"us-east-1"`, `"192.168.1.50"`, `'main'` |
| পূর্ণসংখ্যা (Integer) | `int` | ধনাত্মক/ঋণাত্মক পূর্ণ সংখ্যা | শুধু অঙ্ক | `34`, `2` | `ssh_port = 22`, `active_containers = 5` |
| দশমিক সংখ্যা (Float) | `float` | দশমিকযুক্ত সংখ্যা | অঙ্ক ও `.` | `45.50`, `1.75` | `cpu_utilization_percent = 78.4` |
| বুলিয়ান (Boolean) | `bool` | শুধু `True` বা `False` | `True` / `False` | `has_wife = False` | `is_healthy = True` |
| তালিকা (List) | `list` | ক্রমানুসারে সাজানো অনেকগুলো আইটেম | `[ ]` | `["Liam", "Maya"]` | `["10.0.0.1", "10.0.0.2"]` |
| অভিধান (Dictionary) | `dict` | লেবেলযুক্ত কী → মান জোড়া | `{ key: value }` | `{"name": "Alice"}` | `{"image": "nginx:latest"}` |

### ৭.২ স্ট্রিং (`str`)

**স্ট্রিং** হলো উদ্ধৃতিচিহ্ন বা কোটেশন (Quotation) দিয়ে মোড়ানো *অক্ষরের ধারা (Sequence of Characters)*। স্যান্ডউইচের মতো ভাবুন: লেখাটা ভেতরের পুর, আর দুই পাশের কোটেশন হলো পাউরুটি।

```python
a = 'single quotes'
b = "double quotes"
c = '''triple single quotes'''
d = """triple double quotes —
একাধিক লাইনে
লেখা যায়"""
```

- স্ট্রিং একটা অক্ষর, একটা শব্দ, একটা বাক্য, এমনকি পুরো একটা কবিতাও হতে পারে।
- **প্রতিটি** অক্ষর গোনা হয়, একটা স্পেস `" "`, `$` চিহ্ন বা যেকোনো সিম্বলও।
- **কোটেশন যেকোনো কিছুকে টেক্সট বানিয়ে দেয়:** `"60"` একটা স্ট্রিং, সংখ্যা নয়। `type("60")` → `str`।

**কনভেনশন (প্রচলিত রীতি):** পুরো কোডবেজে **একটাই** কোটেশন স্টাইল বেছে নিন (ডাবল বা সিঙ্গেল) এবং **সবখানে** সেটাই ব্যবহার করুন। মিশিয়ে ফেললে এরর হবে না, কিন্তু কোড পরিচ্ছন্ন থাকে না।

**কোটেশন না দিলে কী হয়?**

```python
print(Hello World)     # ❌ SyntaxError
print("Hello World")   # ✅ Hello World
```

**সিনট্যাক্স (Syntax)** হলো প্রোগ্রামিং ভাষার ব্যাকরণ। "I Noor" ভুল ইংরেজি, কারণ "am" লাগবে। `print(Hello World)` ভুল পাইথন, কারণ টেক্সটের জন্য কোটেশন লাগবে। ব্যাকরণের কোনো অংশ বাদ পড়লে তাকে বলে **সিনট্যাক্স এরর (Syntax Error)**।

### ৭.৩ ইন্টিজার (`int`) ও ফ্লোট (`float`)

```python
age = 60             # int: পূর্ণ সংখ্যা, কোটেশন নেই
price = 102.050      # float: দশমিক আছে
```

- সংখ্যা লেখা হয় কোটেশন **ছাড়া**।
- পাইথনে `int` আর `float` **দুটি আলাদা টাইপ**, একই টাইপের দুই রূপ নয়।
- ফাইন্যান্স ও হিসাবরক্ষণে দশমিক খুব গুরুত্বপূর্ণ, কারণ সেখানে `102.05` ≠ `102`।

### ৭.৪ বুলিয়ান (`bool`)

সারা দুনিয়ায় মাত্র **দুটি** সম্ভাব্য মান: `True` অথবা `False`। প্রথম অক্ষর বড় হাতের, কোনো কোটেশন নেই।

```python
married = True
print(4 > 6)          # False — পাইথন তুলনাটা যাচাই করে
print(type(4 > 6))    # <class 'bool'>
```

⚠️ `"True"` (কোটেশনসহ) একটা **স্ট্রিং**, বুলিয়ান নয়। আর ছোট হাতের `true` লিখলে পাইথনে এরর হবে।

### ৭.৫ লিস্ট ও ডিকশনারি

এ দুটো এত গুরুত্বপূর্ণ যে আলাদা অনুচ্ছেদ পেয়েছে। দেখুন [অনুচ্ছেদ ৮](#৮-লিস্ট-বিস্তারিত) ও [অনুচ্ছেদ ৯](#৯-ডিকশনারি-বিস্তারিত)।

## ৮. লিস্ট বিস্তারিত

> **লিস্ট (List) হলো ক্রমানুসারে সাজানো, পরিবর্তনযোগ্য (Mutable) আইটেমের সংগ্রহ, যা থার্ড ব্র্যাকেট বা স্কয়ার ব্র্যাকেট `[ ]` দিয়ে মোড়ানো এবং কমা দিয়ে আলাদা করা।**

```python
fruits = ["apple", "banana", "orange"]
```

### ৮.১ বৈশিষ্ট্য

- **স্কয়ার ব্র্যাকেট** `[ ]` দিয়ে মোড়ানো।
- আইটেমগুলো **কমা (Comma)** দিয়ে আলাদা (স্টাইল অনুযায়ী প্রতিটি কমার পরে একটা স্পেস)।
- **যেকোনো ডাটা টাইপ** রাখা যায়, মিশিয়েও, এমনকি লিস্টের ভেতরে আরেকটা লিস্টও:

```python
mixed = ["Noor", 60, 12.3, True, ["nested", "list"]]
```

- **একই জিনিস একাধিকবার (Duplicate)** রাখা যায়: `["a", "a", "b"]` চলবে।
- ভেতরের প্রতিটি জিনিসকে বলে **আইটেম (Item)** বা **এলিমেন্ট (Element)**।

স্ট্রিং হলো *অক্ষরের ধারা*। লিস্ট হলো *আইটেমের ধারা*।

### ৮.২ ইনডেক্স (Index): আইটেমের অবস্থান

স্কুলের একটা বেঞ্চে তিনজন ছাত্র বসত: ১ নম্বর, ২ নম্বর, ৩ নম্বর সিট। লিস্টেরও সিট আছে, একে বলে **ইনডেক্স (Index)**, কিন্তু **গোনা শুরু হয় ০ থেকে**। লিস্ট হলো **জিরো-বেসড (Zero-based)**।

```
fruits  =  [ "orange", "banana", "apple" ]
ইনডেক্স:        0         1         2
নেগেটিভ:       -3        -2        -1
```

```python
print(fruits[0])    # orange
print(fruits[1])    # banana
print(fruits[-1])   # apple  (নেগেটিভ ইনডেক্স শেষ থেকে গোনে)
print(fruits[4])    # ❌ IndexError: list index out of range
```

ইনডেক্স `4` ব্যবহার করতে হলে অন্তত ৫টি আইটেম লাগবে (0, 1, 2, 3, 4)। যে অবস্থান নেই সেটা চাইলে পাইথন পরিষ্কার করে জানিয়ে দেয়।

> `.py` ফাইলে শুধু `fruits[1]` লিখে রাখলে **কিছুই দেখাবে না**। মান দেখতে হলে `print()` করতে হবে। (ইন্টারঅ্যাক্টিভ `>>>` REPL নিজে থেকেই মান দেখায়, স্ক্রিপ্ট ফাইল দেখায় না।)

### ৮.৩ প্রতিদিনের লিস্ট অপারেশন (`2. list-data-operations.py` থেকে)

```python
grocery_list = ["Eggs", "Milk", "Bread"]

# যোগ করা
grocery_list.append("Apples")      # একদম শেষে যোগ
grocery_list.insert(1, "Butter")   # ১ নম্বর অবস্থানে যোগ
# → ['Eggs', 'Butter', 'Milk', 'Bread', 'Apples']

# বাদ দেওয়া
grocery_list.remove("Milk")        # মান (VALUE) দেখে বাদ (প্রথম মিলটা)
removed_item = grocery_list.pop(2) # অবস্থান (POSITION) দেখে বাদ, এবং সেটা ফেরত দেয়
print(f"I took this out of the list: {removed_item}")   # Bread

# খোঁজা / গোনা / সাজানো
if "Eggs" in grocery_list:         # আছে কি না → True/False
    print("Yes, you need to buy eggs.")
print(len(grocery_list))           # মোট আইটেম সংখ্যা
grocery_list.sort()                # A → Z, মূল লিস্টটাই বদলে দেয়
```

| মেথড (Method) | কী করে | কীসের ভিত্তিতে বাদ | আইটেমটা ফেরত দেয়? |
|---|---|---|---|
| `append(x)` | `x` শেষে যোগ করে | — | — |
| `insert(i, x)` | `x` কে `i` ইনডেক্সে যোগ করে | — | — |
| `remove(x)` | প্রথম পাওয়া `x` মুছে দেয় | **মান** | না |
| `pop(i)` | `i` ইনডেক্সের আইটেম মুছে দেয় (`i` না দিলে শেষেরটা) | **অবস্থান** | **হ্যাঁ** |
| `len(list)` | আইটেম গোনে | — | — |
| `sort()` | জায়গায় সাজায় (A→Z, ছোট→বড়) | — | — |

**ডেভঅপসে ব্যবহার:** একটা ক্লাস্টারের সার্ভারগুলোর আইপি, অথবা পাইপলাইনের ধাপগুলো:

```python
web_cluster_ips = ["10.0.0.1", "10.0.0.2", "10.0.0.3"]
deployment_pipeline_stages = ["Build", "Test", "Deploy"]
```

## ৯. ডিকশনারি বিস্তারিত

ছোটবেলার ইংরেজি-টু-বাংলা অভিধানের কথা মনে আছে? *Father → বাবা*। একটা **শব্দ (কী)** খুঁজে তার **অর্থ (মান)** পাওয়া যায়। পাইথনের `dict` ঠিক এভাবেই কাজ করে।

> **ডিকশনারি (Dictionary) হলো `key: value` জোড়ার সংগ্রহ, যা কার্লি ব্রেসেস বা সেকেন্ড ব্র্যাকেট `{ }` দিয়ে মোড়ানো। এখানে অবস্থান নম্বর দিয়ে নয়, কী (লেবেল) দিয়ে ডাটা খোঁজা হয়।**

```python
person = {
    "name": "Noor",
    "number_of_kids": 2
}
```

### ৯.১ গঠন

```
{ "name"  :  "Noor" ,  "number_of_kids" : 2 }
  ──────  ─  ──────  ─
   KEY    │  VALUE   └── কমা আলাদা করে একেকটা ITEM
          └── কোলন আলাদা করে কী থেকে মানকে
```

- কার্লি ব্রেসেস `{ }` (বাংলাদেশে যাকে *সেকেন্ড ব্র্যাকেট* বলি)।
- প্রতিটি আইটেম = **কী (Key) : মান (Value)**, মাঝে **কোলন (Colon)** `:`। (সেমিকোলন `;` নয়!)
- একাধিক আইটেম **কমা** `,` দিয়ে আলাদা।
- **মান (Value)** যেকোনো কিছু হতে পারে: str, int, bool, list, এমনকি আরেকটা dict।
- **কী (Key)** সাধারণত স্ট্রিং হয়। কী অবশ্যই **অনন্য (Unique)** এবং **অপরিবর্তনীয় (Immutable)** হতে হবে: `str`, `int`, `float`, `bool` বা `tuple` চলবে। লিস্ট কখনো কী হতে **পারে না**।

প্রতিটি আইটেম আলাদা লাইনে লেখা শুধু পড়ার সুবিধার জন্য। পাইথনের কাছে দুই রকম লেআউটই এক।

### ৯.২ পুরো একটা জরিপ, একটা ভেরিয়েবলে

```python
human_survey_profile = {
    "name": "Alice Smith",
    "age": 34,
    "has_wife": False,
    "kids": ["Liam", "Maya"]      # ডিকশনারির ভেতরে একটা লিস্ট
}

print(human_survey_profile["name"])    # Alice Smith
```

**ডেভঅপস সংস্করণ:** একটা কনটেইনারের কনফিগারেশন।

```python
container_config = {
    "image": "nginx:latest",
    "exposed_port": 80,
    "environment": "production",
    "is_healthy": True
}
print(container_config["exposed_port"])   # 80
```

ডাটা স্ট্রাকচারের মূল কথা এটাই: **আগে ডাটাকে গুছিয়ে সাজাও, তারপর ঠিক যেটুকু দরকার সেটুকু বের করো।** ডেভঅপসে এই `key: value` আকৃতি সবখানে দেখবেন: API-এর JSON রেসপন্স, ডকার কম্পোজ ও কুবারনেটিসের YAML ফাইল, `.env` ফাইল।

### ৯.৩ খোঁজা, যোগ, আপডেট (`3. dictionary-data-type.py` থেকে)

```python
employee_directory = {
    "EMP101": "Anis Rahman",
    "EMP102": "Sultana Kamal",
    "EMP103": "Tamim Iqbal"
}

print(employee_directory["EMP102"])              # খোঁজা → Sultana Kamal
employee_directory["EMP104"] = "Sakib Al Hasan"  # নতুন কী → যোগ (ADD)
employee_directory["EMP101"] = "Khalilur Hasan"  # পুরনো কী → হালনাগাদ (UPDATE/overwrite)
```

একই লেখা `dict[key] = value`: কী নতুন হলে **যোগ করে**, আগে থেকে থাকলে **পুরনো মান মুছে নতুনটা বসায়**।

যে কী নেই সেটা চাইলে `KeyError` হয়।

### ৯.৪ লিস্ট বনাম ডিকশনারি

| | লিস্ট `[ ]` | ডিকশনারি `{ }` |
|---|---|---|
| কীভাবে পাই | অবস্থান নম্বর (ইনডেক্স) দিয়ে | লেবেল (কী) দিয়ে |
| উদাহরণ | `ips[0]` | `config["image"]` |
| কখন ভালো | ক্রম গুরুত্বপূর্ণ; সব আইটেম "একই জাতের" | প্রতিটি মানের নিজস্ব অর্থ বা লেবেল আছে |
| একই জিনিস একাধিকবার | চলে | কী অবশ্যই অনন্য |

## ১০. টাইপ কাস্টিং

### ১০.১ সমস্যা

```python
x = 10
y = "20"
print(x + y)
# ❌ TypeError: unsupported operand type(s) for +: 'int' and 'str'
```

এররটা ধীরে পড়ুন: **TypeError** মানে *ডাটা টাইপের* সমস্যা। সংখ্যার সাথে লেখা যোগ করা যায় না, যেমন বাঘে-মহিষে এক ঘাটে জল খায় না। পাইথন ডাইনামিক্যালি টাইপড বলে এটা নিজেই ধরে ফেলেছে।

### ১০.২ সমাধান: টাইপ বদলে দিন

**টাইপ কাস্টিং (Type Casting)** = একটা মানকে এক ডাটা টাইপ থেকে আরেক ডাটা টাইপে রূপান্তর করা।

```python
print(x + int(y))     # 30  → "20" হয়ে গেল সংখ্যা 20
```

### ১০.৩ উল্টো দিকে রূপান্তর

লক্ষ্য: `20` আর `"26"` জুড়ে সাল `"2026"` বানানো।

```python
x = 20
y = "26"
print(x + y)          # ❌ TypeError
print(str(x) + y)     # ✅ 2026  → 20 হয়ে গেল টেক্সট "20"
```

একই `+` চিহ্ন, কিন্তু কাজ আলাদা:
- `int + int` → **অঙ্ক** (`20 + 26 = 46`)
- `str + str` → **লেখা জোড়া** (`"20" + "26" = "2026"`)

### ১০.৪ কাস্টিং ফাংশনগুলো

| ফাংশন | যাতে রূপান্তর করে | উদাহরণ | ফলাফল |
|---|---|---|---|
| `int()` | পূর্ণসংখ্যা | `int("20")` | `20` |
| `float()` | দশমিক সংখ্যা | `float("3.5")` | `3.5` |
| `str()` | স্ট্রিং | `str(20)` | `"20"` |
| `bool()` | বুলিয়ান | `bool(0)` | `False` |

বাস্তবে সবচেয়ে বেশি লাগে **স্ট্রিং → ইন্টিজার** আর **ইন্টিজার → স্ট্রিং**।

⚠️ `int("hello")` বা `int("3.5")` → `ValueError`। টেক্সটটা দেখতে আসলেই পূর্ণসংখ্যার মতো হলে তবেই পাইথন রূপান্তর করতে পারে।

## ১১. স্ট্রিং জোড়া লাগানো: কনক্যাটিনেশন

**কনক্যাটিনেশন (Concatenation)** = `+` দিয়ে স্ট্রিং জোড়া লাগানো। এটা যোগ-অঙ্ক নয়, জোড়া দেওয়া।

```python
f_name = "Noor"
l_name = "Siddique"

print(f_name + l_name)          # NoorSiddique   ← কোনো স্পেস নেই!
print(f_name + " " + l_name)    # Noor Siddique  ← মাঝে একটা স্পেস স্ট্রিং দিলাম
```

- `""` হলো **খালি স্ট্রিং (Empty String)**, কোটেশনের ভেতরে কিছু নেই।
- `" "` হলো **একটা স্পেসওয়ালা** স্ট্রিং। দুটো শব্দের মাঝে এটাই লাগে।

## ১২. স্ট্রিং ইন্টারপোলেশন

**স্ট্রিং ইন্টারপোলেশন (String Interpolation)** = বাইরে থেকে ভেরিয়েবলের মান একটা স্ট্রিংয়ের *ভেতরে* বসিয়ে দেওয়া।

### ১২.১ f-স্ট্রিং (সুপারিশকৃত)

```python
name = "Noor"
age = 60

bio = f"My name is {name} and my age is {age}"
print(bio)    # My name is Noor and my age is 60
```

দুটো অংশ, দুটোই বাধ্যতামূলক:
1. শুরুর কোটেশনের ঠিক আগে **`f`** অক্ষর।
2. স্ট্রিংয়ের ভেতরে **কার্লি ব্রেসেস `{ }`**-এর মধ্যে ভেরিয়েবলের নাম।

`f` দিতে ভুলে গেলে পাইথন ব্রেসেসসহ হুবহু ছাপিয়ে দেবে: `My name is {name}...`

> **পরিভাষা সংশোধন:** ক্লাসে একে "f ফাংশন" বলা হয়েছে। আসলে এটা একটা **স্ট্রিং প্রিফিক্স (String Prefix)**, আর ফলাফলকে বলে **ফরম্যাটেড স্ট্রিং লিটারাল (Formatted String Literal)** বা **f-string**। এটা কোনো ফাংশন নয়।

বাড়তি সুবিধা: f-স্ট্রিং সংখ্যা নিজেই সামলে নেয়, `str()` কাস্টিং লাগে না। `age` একটা `int` হলেও `f"Age: {age}"` দিব্যি চলে।

### ১২.২ `str.format()` (পুরনো পদ্ধতি)

```python
bio = "My name is {} and my age is {}".format(name, age)
```

খালি `{}` হলো **প্লেসহোল্ডার (Placeholder)**, অর্থাৎ ফাঁকা জায়গা। `.format( )`-এর ভেতরের মান দিয়ে **ক্রম অনুযায়ী** সেগুলো পূরণ হয়।

⚠️ **ক্রম (সিরিয়াল) গুরুত্বপূর্ণ।** কোন মানটা "নাম" আর কোনটা "বয়স", পাইথন জানে না:

```python
"My name is {} and my age is {}".format(age, name)
# → My name is 60 and my age is Noor   😅
```

| | f-স্ট্রিং | `.format()` |
|---|---|---|
| লেখার ধরন | `f"Hi {name}"` | `"Hi {}".format(name)` |
| পড়ার সুবিধা | যেখানে লাগছে সেখানেই ভেরিয়েবলের নাম দেখা যায় | ক্রমটা মাথায় মিলিয়ে রাখতে হয় |
| পরামর্শ | ✅ এটাই ব্যবহার করুন | জেনে রাখুন; পুরনো কোডে দেখবেন |

## ১৩. ইউজার ইনপুট

জিমেইলে লগইন করতে গেলে ইমেইল আর পাসওয়ার্ড চায়। পাইথনে এর সমতুল্য হলো বিল্ট-ইন **`input()`** ফাংশন: একটা বার্তা দেখায়, ব্যবহারকারী (User) টাইপ করা পর্যন্ত অপেক্ষা করে, তারপর যা টাইপ করা হলো সেটা ফেরত দেয়।

```python
first_name = input("Enter your first name: ")
last_name = input("Enter your last name: ")

full_name = first_name + " " + last_name
print(full_name)
```

```
Enter your first name: Noor
Enter your last name: Siddique
Noor Siddique
```

`input("...")`-এর ভেতরের লেখাটা হলো **প্রম্পট (Prompt)**, অর্থাৎ ব্যবহারকারী যে নির্দেশনা দেখেন। এটা ঐচ্ছিক (`input()` খালিও চলে), কিন্তু সবসময় একটা দিন, যাতে ব্যবহারকারী বোঝেন তাঁর কাছে কী চাওয়া হচ্ছে।

### ⚠️ `input()`-এর সোনালি নিয়ম

> **`input()` সবসময় একটা `str` ফেরত দেয়, ব্যবহারকারী সংখ্যা টাইপ করলেও।**

```python
age = input("Enter your age: ")        # ব্যবহারকারী লিখলেন 60
print(type(age))                       # <class 'str'>  → "60"
print(age + 1)                         # ❌ TypeError

age = int(input("Enter your age: "))   # সাথে সাথে কাস্ট করুন
print(age + 1)                         # ✅ 61
```

সংখ্যা দরকার হলে `input()`-কে `int()` (বা `float()`) দিয়ে মুড়ে দিন।

**এখন পর্যন্ত শেখা বিল্ট-ইন ফাংশন (Built-in Function):** `print()`, `input()`, `type()`, `len()`, `int()`, `str()`, `float()`, `bool()`। পাইথন ইনস্টল করার সময় এগুলো সাথে করে নিয়ে আসে, যেমন নতুন কম্পিউটারে অডিও-ভিডিও ড্রাইভার আগে থেকেই দেওয়া থাকে। ফাংশন নিয়ে পরে পুরো একটা ক্লাস হবে।

## ১৫. ল্যাব ১: ধাপে ধাপে সমাধান

**ফাইল:** `Student-Lab-Exercises1.md`, "The Smart Survey Onboarding Engine"

ল্যাবে আজকের ক্লাসের বাইরের দুটো জিনিস লাগবে, তাই আগে একটা ছোট প্রস্তুতি।

### ১৫.১ ছোট প্রস্তুতি: `if / elif / else` আর `and / or`

**শর্ত (Conditional)** দিয়ে প্রোগ্রাম সিদ্ধান্ত নেয়:

```python
if condition_1:
    # condition_1 True হলে এটা চলবে
elif condition_2:
    # condition_1 False এবং condition_2 True হলে এটা চলবে
else:
    # ওপরের কোনোটাই True না হলে এটা চলবে
```

- প্রতিটি শর্তের লাইনের শেষে **কোলন** `:`।
- ভেতরের কোড অবশ্যই **ইনডেন্ট (Indent)** করতে হবে (৪টি স্পেস)। পাইথনে ইনডেন্টেশনই ব্যাকরণ।
- পাইথন ওপর থেকে নিচে দেখে এবং **শুধু প্রথম** মিলে যাওয়া অংশটা চালায়।

**লজিক্যাল অপারেটর (Logical Operator):**

| অপারেটর | কখন `True` | উদাহরণ |
|---|---|---|
| `and` (এবং) | **দুই পাশই** True হলে | `age >= 18 and developer == "yes"` |
| `or` (অথবা) | **অন্তত এক পাশ** True হলে | `role == "admin" or role == "root"` |

তুলনার অপারেটর (Comparison Operator): `<`, `>`, `<=`, `>=`, `==`, `!=` (সমান নয়)।

### ১৫.২ অ্যালগরিদমের মতো পরিকল্পনা

1. নাম জিজ্ঞেস করুন → `str` হিসেবেই রাখুন।
2. বয়স জিজ্ঞেস করুন → **`int`-এ কাস্ট করুন** (সোনালি নিয়ম মনে আছে?)।
3. "ডেভেলপার? yes/no" জিজ্ঞেস করুন → `str` হিসেবে রাখুন।
4. টিয়ার (Tier) ঠিক করুন:
   - বয়স < 18 → `"Tier 3: Guest"`
   - বয়স ≥ 18 **এবং** ডেভেলপার → `"Tier 1: Admin Infrastructure Access"`
   - বয়স ≥ 18 **কিন্তু** ডেভেলপার নন → `"Tier 2: Standard Executive Access"`
5. একটা **f-স্ট্রিং** দিয়ে সারাংশ প্রিন্ট করুন।

## ১৬. ইন্টারভিউ কর্নার

**প্রশ্ন: পাইথন কী?**
একটি হাই-লেভেল, ডাইনামিক্যালি টাইপড, সাধারণ-উদ্দেশ্য (General-purpose) প্রোগ্রামিং ভাষা। CPython সোর্স কোডকে বাইটকোডে কম্পাইল করে এবং পাইথন ভার্চুয়াল মেশিন সেটা ইন্টারপ্রেট করে, তাই এটা একসাথে কম্পাইলড ও ইন্টারপ্রেটেড। এটা কেস-সেনসিটিভও।

**প্রশ্ন: "ডাইনামিক্যালি টাইপড" মানে কী?**
ভেরিয়েবলের টাইপ ঘোষণা করতে হয় না। দেওয়া মান দেখে পাইথন রানটাইমে টাইপ ঠিক করে নেয় (`x = 5` → `int`)।

**প্রশ্ন: পাইথন কম্পাইলড নাকি ইন্টারপ্রেটেড?**
দুটোই। সোর্স → বাইটকোড (কম্পাইল), বাইটকোড → PVM এক স্টেটমেন্ট করে চালায় (ইন্টারপ্রেট)।

**প্রশ্ন: লিস্ট আর ডিকশনারির পার্থক্য কী?**
লিস্ট ক্রমানুসারে সাজানো সংগ্রহ, সংখ্যাসূচক ইনডেক্স দিয়ে পাওয়া যায়। ডিকশনারি অনন্য কী-এর সাথে মান জুড়ে রাখে, কী দিয়ে পাওয়া যায়।

**প্রশ্ন: `input()` কোন টাইপ ফেরত দেয়?**
সবসময় `str`।

**প্রশ্ন: টাইপ কাস্টিং কী? একটা উদাহরণ দিন।**
একটা মানকে এক টাইপ থেকে আরেক টাইপে রূপান্তর: `int("20")` → `20`, `str(20)` → `"20"`।

**প্রশ্ন: `print(10 + "20")` কেন কাজ করে না?**
`TypeError`: পাইথন `int` আর `str` যোগ করবে না। আগে এক পাশ কাস্ট করুন।

## ১৭. পরিভাষা (Glossary)

| ইংরেজি টার্ম | বাংলা অর্থ | প্রসঙ্গ / ব্যাখ্যা |
|---|---|---|
| **Algorithm** | অ্যালগরিদম, কর্মপদ্ধতি | কাজ শেষ করার ধাপগুলোর ক্রম। |
| **Assignment (`=`)** | মান নির্ধারণ | ভেরিয়েবলে মান রাখা। |
| **Boolean (`bool`)** | বুলিয়ান, সত্য-মিথ্যা মান | শুধু `True` / `False`। |
| **Built-in function** | অন্তর্নির্মিত ফাংশন | পাইথনের সাথেই আসে (`print`, `input`, `len`, `type`…)। |
| **Bytecode** | বাইটকোড | কোডের মাঝামাঝি রূপ, PVM চালায়। |
| **Case-sensitive** | বড়-ছোট হাতের অক্ষরে সংবেদনশীল | `Noor` ≠ `noor`। |
| **Comment (`#`)** | মন্তব্য | মানুষের জন্য নোট; পাইথন উপেক্ষা করে। |
| **Concatenation** | সংযুক্তকরণ, জোড়া লাগানো | `+` দিয়ে স্ট্রিং জোড়া। |
| **Data** | ডাটা, উপাত্ত | মেমোরিতে রাখা কাঁচা তথ্য। |
| **Data structure** | ডাটা স্ট্রাকচার, উপাত্ত-কাঠামো | ডাটা সাজানো, ব্যবস্থাপনা, সংরক্ষণ ও ব্যবহারের কাঠামো। |
| **Data type** | ডাটা টাইপ, উপাত্তের ধরন | মানের জাত: `str`, `int`, `float`, `bool`, `list`, `dict`… |
| **Database** | ডাটাবেস, তথ্যভান্ডার | ডাটা জমা রাখে ও চাইলে ফেরত দেয়। |
| **Dictionary (`dict`)** | অভিধান | `{ }`-এর ভেতরে অনন্য `key: value` জোড়া। |
| **Dynamically typed** | চলমান অবস্থায় টাইপ নির্ধারিত | টাইপ ঘোষণা লাগে না, রানটাইমে বোঝা যায়। |
| **Element / Item** | উপাদান / আইটেম | লিস্ট বা ডিকশনারির ভেতরের একেকটা জিনিস। |
| **Empty string (`""`)** | খালি স্ট্রিং | কোনো অক্ষর নেই এমন স্ট্রিং। |
| **Execute** | কার্যকর করা, চালানো | নির্দেশনা বাস্তবে চালানো। |
| **Extension (`.py`)** | ফাইলের এক্সটেনশন | ফাইলের ধরন বোঝায়; পাইথনের জন্য `.py`। |
| **f-string** | এফ-স্ট্রিং | `{ভেরিয়েবল}` বসানো যায় এমন `f"..."` স্ট্রিং। |
| **Float (`float`)** | দশমিক সংখ্যা | দশমিক বিন্দুযুক্ত সংখ্যা। |
| **High-level language** | উচ্চ-স্তরের ভাষা | হার্ডওয়্যার থেকে দূরে, মানুষের ভাষার কাছে। |
| **Index** | সূচক, অবস্থান নম্বর | লিস্টে আইটেমের অবস্থান, ০ থেকে শুরু। |
| **Input / Output (I/O)** | ইনপুট / আউটপুট | কম্পিউটারকে যা দিই / যা ফেরত পাই। |
| **Integer (`int`)** | পূর্ণসংখ্যা | ধনাত্মক বা ঋণাত্মক পূর্ণ সংখ্যা। |
| **Interpreter** | ইন্টারপ্রেটার, দোভাষী | কোড অনুবাদ করে চালায়। |
| **Key / Value** | কী / মান | ডিকশনারিতে লেবেল ও তার ডাটা। |
| **List (`list`)** | তালিকা | `[ ]`-এর ভেতরে ক্রমানুসারে সাজানো, বদলানো যায় এমন সংগ্রহ। |
| **Low-level language** | নিম্ন-স্তরের ভাষা | হার্ডওয়্যারের কাছাকাছি। |
| **Mutable** | পরিবর্তনযোগ্য | তৈরির পরেও বদলানো যায় (লিস্ট, ডিকশনারি)। |
| **Placeholder** | প্লেসহোল্ডার, ফাঁকা স্থান | `.format()`-এর জন্য স্ট্রিংয়ের `{}`। |
| **Program** | প্রোগ্রাম | কম্পিউটারের জন্য নির্দেশনার সমষ্টি। |
| **Prompt** | প্রম্পট, নির্দেশ-বার্তা | `input()` যে বার্তা দেখায়। |
| **REPL** | ইন্টারঅ্যাক্টিভ শেল | `>>>` প্রম্পটওয়ালা পাইথন শেল (Read–Eval–Print Loop)। |
| **Runtime** | রানটাইম, চলাকালীন সময় | প্রোগ্রাম যখন চলছে। |
| **String (`str`)** | স্ট্রিং, অক্ষরমালা | কোটেশনের ভেতরে অক্ষরের ধারা। |
| **String interpolation** | স্ট্রিং ইন্টারপোলেশন | স্ট্রিংয়ের ভেতরে ভেরিয়েবলের মান বসানো। |
| **Syntax / SyntaxError** | সিনট্যাক্স (ব্যাকরণ) / ব্যাকরণগত ভুল | ভাষার নিয়ম / সেই নিয়ম ভাঙা। |
| **Type casting** | টাইপ কাস্টিং, টাইপ রূপান্তর | এক টাইপ থেকে আরেক টাইপে বদলানো। |
| **TypeError** | টাইপ-সংক্রান্ত এরর | বেমানান টাইপ একসাথে ব্যবহার করলে। |
| **Variable** | চলক, ভেরিয়েবল | পরে ব্যবহারের জন্য মান ধরে রাখে এমন নাম। |
| **Zero-based** | শূন্য-ভিত্তিক | গোনা শুরু ০ থেকে। |

## ১৮. এক পাতার চিট শিট

```python
# ── চালানো ────────────────────────────────────────
# python3 --version          ইনস্টল আছে কি না দেখা
# python3 file.py            একটা ফাইল চালানো
# Ctrl + /                   ভিএস কোডে কমেন্ট/আনকমেন্ট

# ── ভেরিয়েবল ও টাইপ ──────────────────────────────
name   = "Noor"         # str   (লেখা)
age    = 60             # int   (পূর্ণসংখ্যা)
cpu    = 75.1           # float (দশমিক)
active = True           # bool  (সত্য/মিথ্যা)
ips    = ["10.0.0.1", "10.0.0.2"]            # list (তালিকা)
cfg    = {"image": "nginx", "port": 80}      # dict (অভিধান)
type(age)               # <class 'int'>

# ── লিস্ট ─────────────────────────────────────────
ips[0]        ips[-1]        len(ips)
ips.append(x) ips.insert(i, x) ips.remove(x) ips.pop(i)  ips.sort()
"10.0.0.1" in ips       # True

# ── ডিকশনারি ──────────────────────────────────────
cfg["port"]             # পড়া
cfg["env"] = "prod"     # যোগ (নতুন কী)
cfg["port"] = 8080      # আপডেট (পুরনো কী)

# ── কাস্টিং ───────────────────────────────────────
int("20")  str(20)  float("3.5")  bool(0)

# ── স্ট্রিং ───────────────────────────────────────
"Noor" + " " + "Siddique"                    # কনক্যাটিনেশন
f"My name is {name}, age {age}"              # f-string ✅
"My name is {}, age {}".format(name, age)    # ক্রম গুরুত্বপূর্ণ

# ── ইনপুট ─────────────────────────────────────────
city = input("City: ")                 # সবসময় str
age  = int(input("Age: "))             # সংখ্যার জন্য কাস্ট

# ── মনে রাখুন ─────────────────────────────────────
# =  মান রাখে        ==  তুলনা করে
# /  → float         // → পূর্ণসংখ্যা
# লিস্ট শুরু ইনডেক্স 0 থেকে
# পাইথন কেস-সেনসিটিভ
```
